# 修士論文の構成案

作成日: 2026-09-11 / 更新日: 2026-09-12

第3章と付録A〜Cの第1稿、第4章のLLA・補正LLAの原稿は[ドラフトの入口](README.md)から参照できる。Markdownで下書きし、最終稿はLaTeXへ移す。

本書は、研究の問いに答えるために各章で何を説明するかを定める構成案である。章名・章番号・掲載位置は仮置きとし、研究条件の変更や未実施の解析の実施決定を意味しない。

最終稿はLaTeXへ移す計画とし、大学・研究室の提出書式と本文の言語は引き続き未確認とする。実際にある原稿は[原稿案内](README.md)、執筆順・数式と図表の配置・参照実装は[執筆計画](writing_plan.md)で管理する。

## 1. 推奨する章の分け方

「材料および測定」を一章とし、Methodsに相当する内容を「解析手法」と「比較実験・評価および解釈の設計」の二章に分ける。

| 章 | 仮の章名 | 読者に答える問い | 今の扱い |
| --- | --- | --- | --- |
| 第1章 | 緒言 / Introduction | なぜこの問題を扱い、何を明らかにするか | 目的と背景のメモ |
| 第2章 | 材料および測定 / Materials and Measurements | 何を、どの条件で測定したか | 情報待ち。見出しを予約 |
| 第3章 | 解析手法：スペクトル表現学習と空間マッピング / Spectral Representation Learning and Mapping | 観測スペクトルからどう表現とマップを得るか | 第1稿あり |
| 第4章 | 比較実験・評価および解釈の設計 / Evaluation and Interpretation Protocol | 何を比較し、どの証拠で評価・解釈するか | LLA・補正LLAの原稿あり。他は固定済みの部分から執筆 |
| 第5章 | 結果 / Results | 比較と観測で何が得られたか | 項目と必要な図表を予約 |
| 第6章 | 考察 / Discussion | 結果が研究の問いに何を意味し、どこに限界があるか | 論点を予約 |
| 第7章 | 結論 / Conclusions | 研究の問いにどこまで答えられたか | 後で執筆 |
| 付録 | Appendices | 詳細を確認・再現するために何が必要か | A〜Cの定義・実装に基づく第1稿あり。D・Eは未執筆 |

Methodsは第3・4章をまとめた呼び方として使える。単にAnalysisとすると、解析の手順と解析結果のどちらを指すかが曖昧になるため、章名には具体的な内容を使う。一章にまとめる書式が必要なら、第3・4章をMethods配下の二つの大節へ統合できる。

第3章は研究の手法上の中心なので、他章より長くてもよい。長さへの対処は、まず節ごとの責務と本文・付録の分担で行う。独立した「理論」章や手法ごとの章を最初から増やす必要はない。

論証は第1章の問いを起点に、第3章で手法、第4章で比較と解釈に用いる証拠、第5章で得られた観測、第6章でその意味と限界へ進む。以降の章別項目は、この流れの中で各章に残す論点を示す。実験の固定条件は[`docs/design/`](../docs/design/README.md)を参照する。

既存研究とMAE等の採用理由はここにまとめ、第3章では本研究の設計に直接必要な説明を短く参照する。[研究概要](../docs/research_overview.md)は目的の下書き、[位置づけ](../docs/chemomae_positioning.md)と[関連研究](../docs/related_work.md)は論点・引用候補に使う。新規性の優先権や他材料への有効性を、この計画で確定しない。

## 3. 第2章：材料および測定

### 2.1 供試材料

由来、樹種、試料ID、採用・除外、試料の状態、測定面、保管・測定前処理を記載する。未整理の情報は空欄または執筆メモとして残す。現行解析の49試料という対象範囲と、取得試料の全体数・採取関係を混同しない。

### 2.2 NIR-HSIの測定

装置、照明、配置、走査、取得波長、空間分解能、取得条件、white/dark referenceの測定を記載する。ここは観測の取得までとし、反射率への数値変換、マスク、補間、SNVは第3章に置く。200 Hzや256 bandsという入力情報だけから、装置の波長分解能・画素実寸・試料状態を推定しない。

### 2.3 位置対応FT-IR測定【詳細未確定のため予約】

実施が具体化した時点で、装置・測定方式・条件・測定領域・位置対応の実作業を記載する。対象を選ぶ基準やNIRマップとの解釈手順は第4章から参照する。現行資料は計画段階なので、実施済みのMethodsとして文章を完成させない。

MaterialsとMeasurementsを別章にするかは、この章の分量が分かってから再検討できる。今は一章内の別節としておけば、試料情報が未整理でも第3章以降を書ける。

## 4. 第3章：解析手法

### 3.1 解析の全体像と入出力

- 一つの入力は、1画素の256チャネルスペクトルであること。
- 前処理、表現学習、全帯域可視での抽出、クラスタリング、画素位置への配置を一枚の図で示す。
- encoderへ近傍画素・空間座標を入力しないことを明記する。
- 学習時に使うdecoderと、マップ作成時に使うencoder・クラスタ中心を区別する。
- CVでの適用と全体fitによる記述的解析を予告し、対象範囲は第4章で定義する。

### 3.2 共通前処理とSNVスペクトル

1. 200 Hz生強度に基づくMulti-Otsuマスクと後処理。
2. white/dark referenceを使う反射率変換。
3. reference由来SNR proxyに基づく終端帯域の除外。
4. 保持範囲内の等間隔256点への線形補間。
5. 非有限値・分散・負の反射率に関する有効画素の条件。
6. 標本標準偏差を用いる画素単位SNVと、平均ゼロ・一定normの性質。

本文には処理順、主要条件、反射率・SNVの式、SNVが保持・除去する情報を残す。cutoffの詳細診断、mask処理の細部、除外数の表、全試料の確認図は付録Aへ置く。

負の反射率の除外は補間後・SNV前であり、SNVの負値を除外する処理とは書かない。referenceの列方向のばらつきから作るproxyを、反復撮像で測定した時間方向SNRとは呼ばない。

### 3.3 SNV制約を保つスペクトル摂動

1. 追加摂動前の観測から学ぶdenoisingという狙いと、SNV制約に沿う設計。
2. Tangent Gaussian Noise：接方向の生成と角度による回転。
3. Fractional Shift：波長チャネル上の線形補間と、再中心化・再正規化。
4. 適用確率、操作順、強度分布、学習時と評価時の使い分け。
5. この操作で保持する制約と、化学状態の保存について未保証の範囲。

TGN・shiftの定義式と操作例は本文に置く。平均・normが保存される証明、接方向の導出、極小normへの処理は付録Bへ置く。追加のスペクトル例と強度候補を並べた既存のsanity図は付録Aの候補とし、提案の有効性を検証する実験とは区別する。

### 3.4 Masked denoisingによる表現学習

1. 連続帯域のpatch化、位置情報、可視patchとCLSを使うTransformer encoder。
2. CLSから得る16次元の単位潜在と、bias付き線形decoderによる256チャネル復元。
3. 追加摂動前の観測をtargetとする学習課題、mask領域のMSE。
4. 学習時と利用時の違い：学習後は全patch可視、augmentationなし、encoder固定で抽出。

本文にはモデル図、潜在・再構成の式、損失の式、入力maskとloss対象の意味を残す。cleanは「追加摂動前の観測」であり、測定ノイズのない真値とはしない。標準的なattention内部式、各層の設定一覧、初期化・最適化の細部は付録B・Cに配置できる。固定epoch・重みの採用規則など比較に必要な学習条件は第4章に要約する。

PCAとの関係は、非線形な座標推定と線形再構成制約の説明に必要な範囲を本文に置く。単位潜在の像、復元可能なアフィン部分空間などの詳しい議論は付録Bで扱える。

### 3.5 Cosineクラスタリングと空間マッピング

1. クラスタリングへ渡す表現の行ごとのL2正規化。
2. Cosine-KMeansの中心推定と、固定中心への割当。
3. クラスタラベルを元の有効画素座標へ戻してマップを作る処理。
4. 背景と有効画素の区別、クラスタ番号に順序や化学的意味を与えない規約。

本文には類似度・割当の定義を置き、停止条件・初期化・数値設定は付録Cに整理する。クラスタ数、fitする試料の範囲、比較する表現条件は第4章で定義する。vMFは第4章の補助実験で位置づけ、数値仕様の確定後に必要なモデル説明を加える。

## 5. 第4章：比較実験・評価および解釈の設計

### 4.1 比較の問いと条件

主7条件を、表示名・ID・表現次元・mask率・摂動・loss対象・比較上の役割の表にまとめる。B0は前処理済みSNV、B1はPCA、A0は全領域再構成AE、M00は追加摂動なしのMAE、M10・M01・M11はTGN・shiftの単独／併用条件と説明する。

M11対B0・B1・M00の主要比較と、AE/MAE比較、2×2 ablationの問いを対応づける。M00は本研究の共通architectureを用いた対照であり、原MAEの画像用architectureそのものとはしない。M00対A0ではmaskとloss対象が同時に異なるため、mask率のみの効果とは解釈しない。

### 4.2 試料分割と学習画素の抽出

- KYOw単位のランダム5-fold、樹種層化なし、固定split。
- 同一KYOwをtrain/test双方へ含めず、PCA・encoder・中心をtrainだけでfitする。
- trainは各試料8192画素の共通抽出、testは全有効画素。
- 抽出画素を条件・クラスタ数・学習反復で共有する。
- 異なるKYOw間の同一原材関係は不明であり、由来的な独立性を確認したとはしない。

材料の由来が未整理でも、確認済みの解析上の分割単位は書ける。物理的な試料の説明は第2章へ参照を置く。

### 4.3 学習条件・反復・クラスタ数

固定splitでの3反復、共通の学習recipe、800 epochの最終重みの使用、early stoppingやtest指標による重み選択をしない方針を記載する。共通の7種類のクラスタ数と代表表示K=8を示し、K=8だけから結論を決めないことを説明する。本文は主要条件の表、付録Cは詳細設定と再現情報の表にする。

### 4.4 主評価と補助診断

- 主評価：LLA-3/5/9による空間的一貫性、noise・shift・両方のLFRによる指定摂動への安定性。
- 補助診断：補正LLA、cosine-silhouette、反復間ARI。
- 必須併記：occupancy、使用クラスタ数、有効対象数。

本文にLLA・LFRの定義、近傍と有効画素の扱い、摂動条件、指標の解釈範囲を残す。LFRは固定モデルに対し各種類5 drawsとし、学習の3反復と分けて説明する。

LLAは、クラスタ指示関数と中心を除いた近傍カーネルの畳み込みを用いて表す。分子は同一ラベルの有効近傍対数、分母は全有効近傍対数とし、局所一致率の画素単純平均と区別する。ゼロ拡張による背景・除外画素・画像外の扱い、占有率による補正と未定義条件までを[第4.4節の原稿](chapters/evaluation_protocol/metrics_aggregation.md)に記載した。

silhouetteはfoldのtest画素をまとめた距離計算を行った後、試料ごとに要約することを記載する。ARIは同一画素上の3組の反復対を比較する。単一クラスタ化でも良好なLLA・LFRになり得る点を、付録だけに追いやらない。

### 4.5 集計と計画比較

OOF試料を等重みで集計し、同じ試料・K・反復の対応差を報告する。試料間SDと3反復間SDを区別し、未定義値の理由と共通対象数を保持する。2×2交互作用contrast、指標間のtrade-off、全Kでの傾向を扱う。有意差検定・総合score・結果によるbest条件選択を追加しない。

集計式の展開、各指標の退化ケース、silhouetteの計算上の詳細は付録Dに置く。

### 4.6 補助実験【確定範囲から記述】

mask率25%・50%・75%の感度解析と、vMFによるクラスタリング手法への依存性の検討を記述する。mask率50%は主条件M11を再利用する。vMFは主7条件の既存表現を使う計画だが、数値仕様と専用pipelineは未完了なので、その部分の実施記述は保留する。

本文には補助実験の問いと主要条件、結果章には主要な傾向を残す。追加曲線・全比較表・数値解法の細部は付録へ置ける。本文の結論が依存する比較を、「補助実験」という名称だけを理由にすべて付録へ移さない。

### 4.7 全体fitによる可視化と化学的解釈【設計と実施状況を区別】

- 全49試料に基づく共通表現・中心のfitと、全有効画素への適用。
- B0・B1・A0・M00・M11、K=8、Cosine-KMeans・vMFという現行の計画範囲。
- A0のCosine-KMeansを基準とする表示番号の整列。
- 固定7代表試料の選択規約、全試料のマップ保存。
- 観測反射率・SNVのクラスタ別代表線と差スペクトルの作り方。
- 位置対応FT-IRで何を検討するか。未確定の測定・解析条件は執筆メモとして残す。

試料内中央値から試料間中央値・四分位範囲を求める要約と、寄与試料数を記載する。CVの未知試料評価と、全体fitで得る記述・仮説を区別する。現在のB0・B1 OOF sanityはfold内B0基準なので、全体fitの図として流用しない。
