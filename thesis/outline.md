# 修士論文の構成案

作成日: 2026-09-11 / 更新日: 2026-09-13

各章が研究の問いにどう答えるかを定める。章名・番号・掲載位置は仮置き。原稿の有無は[README](README.md)、執筆順・資料・図表は[執筆計画](writing_plan.md)、研究条件は[設計文書](../docs/design/README.md)で管理する。提出書式と本文の言語は未確認である。

## 1. 推奨する章の分け方

| 章 | 仮の章名 | 読者に答える問い |
| --- | --- | --- |
| 第1章 | 緒言 / Introduction | なぜこの問題を扱い、何を明らかにするか |
| 第2章 | 材料および測定 / Materials and Measurements | 何を、どの条件で測定したか |
| 第3章 | 解析手法：スペクトル表現学習と空間マッピング / Spectral Representation Learning and Mapping | 観測スペクトルからどう表現とマップを得るか |
| 第4章 | 比較実験・評価および解釈の設計 / Evaluation and Interpretation Protocol | 何を比較し、どの証拠で評価・解釈するか |
| 第5章 | 結果 / Results | 比較と観測で何が得られたか |
| 第6章 | 考察 / Discussion | 結果が研究の問いに何を意味し、どこに限界があるか |
| 第7章 | 結論 / Conclusions | 研究の問いにどこまで答えられたか |
| 付録 | Appendices | 詳細を確認・再現するために何が必要か |

第3章で解析操作、第4章で比較・解釈の規約を説明する。Methodsは両章の総称とし、提出書式が一章を求める場合は二つの大節へ統合する。独立した理論章は設けず、主要な定義を本文、導出と再現上の詳細を付録へ置く。

## 2. 第1章：緒言

状態区分や正解ラベルを定めにくい材料の評価課題から、古材・NIR-HSIを用いる意義、スペクトルに重なる変動、既存の次元削減・自己教師あり学習・マッピングへ進む。その上で研究の目的と問いを示す。

[研究概要](../docs/research_overview.md)を目的、[位置づけ](../docs/chemomae_positioning.md)と[関連研究](../docs/related_work.md)を採用理由・引用候補の根拠とする。第3章では本設計に必要な採用理由だけを再掲する。新規性の優先権や他材料への有効性は、確認した証拠の範囲で述べる。

## 3. 第2章：材料および測定

### 2.1 供試材料

由来、樹種、試料ID、採用・除外、状態、測定面、保管・測定前処理を記載する。現行解析の49試料と取得試料全体の数・採取関係は別に確認する。未整理情報は執筆メモに残す。

### 2.2 NIR-HSIの測定

装置、照明、配置、走査、取得波長、空間分解能、取得条件、white/dark referenceの測定を記載する。観測の取得までを本節、反射率への数値変換以降を第3章とする。200 Hz・256 bandsから波長分解能や画素実寸を推定しない。

### 2.3 位置対応FT-IR測定【詳細未確定のため予約】

実施後に装置、方式、条件、測定領域、位置対応の実作業を記載する。対象選定と解釈手順は第4章に置く。現在は計画段階である。

## 4. 第3章：解析手法

第1稿の定義・式は各原稿を参照する。ここでは各節の役割と本文・付録の境界を示す。

### 3.1 解析の全体像と入出力

1画素の256チャネルスペクトルから表現とマップを得る流れを示す。学習時のdecoderと、利用時の固定encoder・中心を区別し、座標・近傍画素をencoderへ入力しないことを明記する。CVと全体fitのfit範囲は第4章で定義する。

### 3.2 共通前処理とSNVスペクトル

マスク、反射率変換、reference由来の波長選択、共通grid補間、品質判定、SNVの処理順と主要条件を説明する。本文には反射率・SNVの式と保持／除去する情報、付録Aにはcutoff診断・除外規約・確認図を置く。負値除外はSNV前の反射率に対する条件、SNR proxyはreferenceの列方向の比として記述する。

### 3.3 SNV制約を保つスペクトル摂動

TGNの接方向と回転、Fractional Shiftの補間と再投影、強度分布、適用確率・順序を定義する。本文には操作と仮定、付録Bには制約保存の証明・退化条件を置く。強度確認用のsanity図は付録Aの候補とし、化学状態の保存や性能改善の証拠とは区別する。

### 3.4 Masked denoisingによる表現学習

波長patch・位置情報・可視token、Transformer encoder、16次元単位潜在、bias付き線形decoder、不可視帯域MSE、全帯域可視での抽出を定義する。Random maskもcorruptionであり、TGN・shiftを追加corruptionとして扱う。Cleanは追加摂動前の観測である。

本文には復元課題と利用時の表現、付録Bには入力差・潜在差・残差の対応と摂動応答、付録Cには層構成・最適化等の全設定を置く。付録B.5は数理的補足であり、対応する補助診断一式は現行の実施計画に含めない（[判断理由](../docs/design/representation_geometry_diagnostics.md)）。MAE条件間の違いは、第4章の既定比較・評価と観測スペクトルの解釈に基づいて記述する。

### 3.5 Cosineクラスタリングと空間マッピング

表現のL2正規化、Cosine-KMeansの中心推定・固定割当、元座標への配置を定義する。本文に類似度・割当・背景ラベルとクラスタ番号の意味、付録Cに初期化・停止・退化の規約を置く。Fit対象、共通K、表示整列の基準は第4章で定める。

## 5. 第4章：比較実験・評価および解釈の設計

### 4.1 比較の問いと条件

[実験プロトコル](../docs/design/experiment_protocol.md)の主7条件を、ID・次元・mask・摂動・loss対象・比較上の役割の表にする。M11対B0・B1・M00、AE/MAE比較、MAE内のTGN・shiftの2×2比較を対応づける。M00は共通architectureによる対照であり、原MAEの画像用architectureそのものではない。M00対A0ではmaskとloss対象の両方が変わる。

### 4.2 試料分割と学習画素の抽出

KYOw単位の固定ランダム5-fold（樹種層化なし）を用い、PCA・encoder・中心はtrainのみでfitする。Trainは各試料8192画素を条件・K・反復で共有し、testは全有効画素とする。同一KYOwはtrain/testにまたがらないが、異なるKYOw間の同一原材関係は不明である。

### 4.3 学習条件・反復・クラスタ数

固定splitで3反復、共通recipe、800 epochの最終重み、early stopping・test指標による重み選択なしを記載する。共通の7種類のKと代表表示K=8を示し、全Kの傾向を評価する。本文は主要条件、付録Cは詳細と最終再現情報の表にする。

### 4.4 主評価と補助診断

| 役割 | 指標・併記量 |
| --- | --- |
| 主評価 | LLA-3/5/9、noise・shift・両方のLFR |
| 補助診断 | 補正LLA、cosine-silhouette、反復間ARI |
| 必須併記 | Occupancy、使用クラスタ数、有効対象数 |

LLA・補正LLAの定義、近傍対の正規化、境界・未定義条件は[現稿](chapters/evaluation_protocol/metrics_aggregation.md)にある。残りは[評価指標](../docs/design/evaluation_metrics.md)に従って執筆する。LFRの5 drawsと学習3反復、fold全testで距離を計算してから試料要約するsilhouette、同一画素上の3反復対のARIを区別する。単一クラスタ化でLLA・LFRが良好になり得る点は本文に残す。

### 4.5 集計と計画比較

OOF試料を等重みで集計し、同じ試料・K・反復の対応差、2×2交互作用contrast、指標間のtrade-offを報告する。試料間SDと反復間SD、未定義理由と共通対象数を区別する。有意差検定・総合score・結果によるbest条件選択は追加しない。詳細な集計式と退化条件は付録Dに置く。

### 4.6 補助実験【確定範囲から記述】

Mask率25%・50%・75%の感度解析と、vMFによるクラスタリング方法への依存性を扱う。50%はM11を再利用する。vMFは主7条件の既存表現を用いる計画だが、数値仕様・専用pipelineは未完了である。本文に問い・主要条件・主要な傾向、付録に追加曲線・全比較・数値解法を置く。

### 4.7 全体fitによる可視化と化学的解釈【設計と実施状況を区別】

[可視化・解釈設計](../docs/design/visualization_and_interpretation.md)に従い、全49試料の共通fit、B0・B1・A0・M00・M11、K=8、Cosine-KMeans・vMFを扱う。A0のCosine-KMeansを表示整列基準とし、固定7代表試料と全試料マップを示す。

観測反射率・SNVの代表線は試料内中央値から試料間中央値・四分位範囲を求め、寄与試料数を併記する。差スペクトルと位置対応FT-IRで化学的対応を探索する。CVの未知試料評価と証拠の役割を分け、fold内B0基準のOOF sanityを全体fit図へ流用しない。

結果の節を第4章の問いに対応させ、観測後に優劣と解釈を記入する。
