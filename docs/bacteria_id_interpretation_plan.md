# Raman補助実験の解釈

Bacteria-IDは、古材NIR-HSIとは異なる分光モダリティでChemoMAEの表現を評価する補助実験である。
教師なしクラスタリングと、事前学習後の30 isolate分類を区別する。
条件は[実験仕様](design/bacteria_id_experiment_plan.md)と[分類プロトコル](design/bacteria_id_hpo_protocol.md)、
数値の保存先は[成果物一覧](results.md)を参照する。

## 教師なしクラスタリング

Table 4は、ラベルを損失に使わず学習した128次元表現が、Bacteria-4/6のisolate区分に
関連する情報を保持するかを評価する。各subsetのtrainのみで事前学習とCosine-KMeansのfitを行い、
固定した中心をtestに適用する。ACC・NMI・AMIは5 seedの平均と標本SDを報告する。

M11は両subsetでM00より平均AMI・NMIが高く、平均ACCはM00が高い。
これらは別々の一致尺度であり、いずれか一つから識別性能全体の優越性を判断しない。
学習からクラスタリングまでの反復間変動も大きく、平均値と各seedの結果を併読する。

この結果は、空間座標を使わないRaman課題でも、自己教師あり学習が識別に有用な情報を
集約できることを示す。一方、複数帯域間の依存関係を使ったのか、限られたピークや他の要因を
使ったのかを同定する実験ではない。古材の16次元表現とは入力・潜在次元・重みが異なり、
木材マップの化学的な正しさやLLA改善の機構を直接検証する証拠にはならない。

## 事前学習後の分類

Table 5は、reference 60,000件で事前学習したモデルを、各isolate 100件、計3,000件の
ラベル付きスペクトルで30クラス分類へ適応させた結果である。
M11のfinetune内5-fold CVで選んだ1設定をM00/M11に共通適用し、
各5 seedの最終test Accuracyとt分布による95%信頼区間を報告する。
投影前CLSに分類headを接続するため、Table 4の128次元潜在をそのまま分類器へ渡す実験ではない。
両表は学習コーパスとcheckpointも異なる。

両条件の平均Accuracyは80%を超え、M11はM00を上回らない。
限られた学習ラベルによる下流適応の利用例であるが、同一モデルの事前学習なし条件や
ラベル数を変えた評価はないため、事前学習の因果的な利得やラベル効率は未評価である。
共通分類設定はM11で選択しており、M00に最適な設定を探索した比較でもない。

件数はスペクトル数であり、各isolateに100個の独立した個体・測定群があることを意味しない。
対象は既知isolateの分類で、未知isolate・患者への汎化は未評価である。
分類のAccuracyから木材の物性予測精度や空間マップの信頼性を推定しない。

## 文献値との比較

既存手法の数値は[SMAE出版版](https://doi.org/10.1016/j.eswa.2025.128576)のTable 4・5から引用した報告値であり、
本研究では再実行していない。参照版・クラス構成・前処理・分割・指標の定義は
[実験仕様](design/bacteria_id_experiment_plan.md)にまとめる。

- Table 4では、本研究のtrain/testは80/20%である一方、RamanClusterは60/20/20%である。
  Bacteria-6のクラス構成も資料間で異なり、文献の個別test indexは照合できない。
  引用行にはseed別の値がないため、ChemoMAEの標本SDだけから統計的優越性を推定しない。
- Table 5では、前処理、事前学習、encoderの更新範囲、checkpoint選択、反復の開始点、
  信頼区間の算出法が完全には一致しない。TCLPの値は原論文の結果ではなく、SMAEでencoderを置き換えた報告値である。
- SMAEのFig. 10は複数の設計条件に対する分類精度を示し、その最良値83.9%はTable 5と一致する。
  同じ評価集合を設定選択と最終評価に用いる場合は選択バイアスが生じ得る。
  本研究ではfinetune内のCVで設定を選び、testを分離している。

文献値との大小は参考比較であり、同じ前処理・学習割合・探索予算での厳密な順位やSOTAを示すものではない。
信頼区間の重なりだけで有意差を判断しない。
