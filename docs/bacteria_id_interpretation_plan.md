# Raman補助実験の位置づけと結果解釈計画

本書は[Bacteria-ID実験計画](design/bacteria_id_experiment_plan.md)に沿って、SMAE出版版
Table 4・5へChemoMAE(M00/M11)を追加した結果を、古材NIR-HSI研究の中でどう読むかを定める。
Table 4の主結果は旧testを維持したtrain 80%／test 20%で再学習した値とする。
Table 5は[現行のpartial fine-tuning HPO](design/bacteria_id_hpo_protocol.md)に従い、事前学習・HPO・分類を変更しない。
論文原稿の正本は隣接する`Thesis`リポジトリにあり、このチャットからは**read-only**とする。
執筆上の判断は本リポジトリの`docs`へ記録し、Thesisの原稿・執筆メモは変更しない。
論文側の研究目的と現行の仮説は`Thesis/docs/research_intent.md`および
`Thesis/chapters/06_results_and_discussion.tex`の第6.2・6.4節を参照した。

## 研究全体での役割

研究の到達点は、古材のNIR-HSIによる面的なスペクトル観測と、測定部位を画像上の位置に対応付けた
FT-IRによる局所的な化学情報を合わせ、化学状態の空間分布とその意味を検討することである。
ChemoMAEによる教師なしマップとLLAによる未知試料での空間的一貫性の評価が主実験であり、
RamanのBacteria-IDは**スペクトル表現の外部課題での能力を調べる補助実験**とする。

| 証拠 | 直接評価すること | そこから直接は言えないこと |
| --- | --- | --- |
| 古材NIR-HSIのOOF・LLA | 空間情報を学習・平滑化に使わずに得た分割の、未知試料での局所的な空間的一貫性 | 化学状態の正解、帯域間関係という改善機構の同定 |
| 位置対応FT-IRと試料内NIR | 選んだ部位の化学的所見とクラスタの空間分布との対応 | 未測定画素を含む全域の正解ラベルや物性値 |
| Raman Table 4 | ラベルを学習に用いないChemoMAE表現が、Bacteria-4/6のisolateクラスに関連する差をクラスタリングで保持するか | NIRでどの帯域間関係を学んだか、木材マップの化学的正しさ |
| Raman Table 5 | 事前学習済みChemoMAEを各isolate 100スペクトルの学習ラベルで適応させたときの30 isolateクラスtest精度。M11の5-fold CVで設定を選び、M00/M11の5 seed結果を示す | 事前学習なしChemoMAEに対する改善量、ラベル効率、木材物性の予測・面推定精度 |

Table 4とTable 5は学習コーパスとcheckpointが異なるため、「Table 4で評価した同じ表現が
Table 5の精度を生んだ」という直接の因果連鎖としては扱わない。同じ手法の二つの能力を別々に調べる。

## Table 4：教師なし表現の識別能力

各subsetの保存済み旧trainと旧validationの和集合を新trainとして、各seedを初期化から固定800 epochで
事前学習する。新train全件でCKmeansをfitし、保存済み旧testのindex・順序を維持して
ACC・NMI・AMIを測る。Table 4にvalidation・HPO・early stoppingは設けない。
結果はChemoMAEの5 seed平均±標本SDを示し、各seedの値も保持する。
文献行は[SMAE出版版の報告値](design/bacteria_id_experiment_plan.md)であり、
同条件の再実行値ではない。SMAE Table 4の既存5手法はRamanCluster Table 1と30数値中29数値が一致し、
Bacteria-6の実際の対象ID・分割indexに加え、文献手法の学習割合・評価手順の一致も確認できない。

M11が比較表で最も高い平均値を得ても、「報告値との**数値上の比較**」とする。
seed間のばらつきとBacteria-6のクラス構成の不確実性を併記し、厳密な同条件SOTAや統計的優越性とは書かない。
成績が一部seedに依存する場合は、その不安定性も結果として記述する。
M00/M11の差は同じ分割・評価手順下での事前学習時のTGN/FS併用の有無に対応するが、
木材のLLA改善の原因まで特定するものではない。

本実験が支持するのは、ChemoMAEが**空間座標を使わない別のスペクトル課題でも、識別に有用な情報を
自己教師ありで保持し得る**という点である。これは、古材でのマスク復元が状態差に関わる帯域間の
関係を集約した可能性と整合する。一方、クラス分離だけでは、複数帯域間の依存関係を利用したのか、
限られたピークや他の要因を利用したのかは分からず、「帯域間関係を学んだことを証明した」とは書かない。
Ramanでは潜在128次元、古材では16次元であり、同じ重み・同じ表現を直接評価した実験でもない。

## Table 5：限定したラベル数での下流適応

referenceの60,000スペクトルをラベルなしで事前学習する。finetune subset 3,000件
（30クラス×100件）を5-foldに層化分割し、各foldのtrain 2,400件でCLS分類headと
最後の`k`個のTransformer blockを学習する。`k=0..8`、head/encoder block学習率、
batch size、TGN/FS、weight decayを探索した。当初100件の異なる設定を予定したが、
64件が完了し、最初の60件を選択対象とした。
各trialはM11の事前学習seed 0で5-foldを50 epoch固定で学習し、foldごとの**epoch 50**の
validation Accuracy平均で設定を選ぶ。M00/M11の各5 seedについて、採用設定で
finetune 3,000件すべてを50 epoch学習し、epoch 50の重みでtest 3,000件を採点する。
5 seedの平均Accuracy±95% CIを報告する。M00/M11には同じ分類設定を適用し、
主な条件差を事前学習時の追加Augの有無に限定する。分類headはCLSにのみ接続し、
投影`z`はTable 4のクラスタリング用表現と位置づける。

付録・補助資料には、探索空間、完了64設定の5-foldのepoch 50 Accuracyと
選択に用いた先頭60件の範囲、
採用設定と各seedのtest値を示す。非採用候補のtestは測らない。
HPO履歴は設定がtrialごとに変わるため、`k`単独の効果を示す統制図とは解釈しない。

文献上の参照値はSMAE Table 5の`w/ pretraining`列にある報告値（Jensen 81.60%、
改変TCLP 82.30%、SMAE 83.90%）とする。平均値がこの範囲内または上に入り、seed間でも
大きな崩れがなければ、**このtest上では既報と近い数値水準**と記述できる。
83.90%を超える場合も「validationで共通設定を選んだChemoMAEの観測値がSMAE報告値を
数値上上回る」にとどめ、厳密な同条件比較や統計的優越性としない。
範囲より低い、またはseed間の変動が大きい場合は、今回固定した事前学習と
探索範囲での結果として報告する。結果を見てseed・checkpointを選び直したりしない。
信頼区間の重なりだけで有意差を判定しない。

本補助実験はSOTAや「小ラベルで高精度」を主張するためのものではない。
最終学習のラベルは計3,000スペクトル（各isolate 100件）であり、独立した試料・測定位置が
各クラス100個あることを意味しない。ラベル数を変えた実験や同一モデルの事前学習なし条件を
設けないため、few-shot性能やラベル効率を実証したとも書かない。Fig. 10の
`Finetune Acc`の分布を、ChemoMAEが「同等」とみなされる許容範囲として使わない。
結果の大小にかかわらず、実際のラベル数、test Accuracy、seed間のばらつきを具体的に示す。

WoodDegradationMap由来の事前学習recipeとRaman用に固定したモデル構成について、
事前学習のハイパーパラメータは結果を見て探索していない一方、分類学習は
validationを用いて上記のHPOを行ったことを明記する。
得られた精度はこの事前学習済みモデルの下流適応を評価する材料になるが、低精度の原因を
特定の学習設定だけに帰さない。
他手法の前処理・pretraining・encoder更新範囲・checkpoint選択・CI算出法は完全には揃っていない。
TCLPの82.30 ± 0.5%はSMAE著者がencoderを置き換えてBacteria-IDで報告した値であり、
TCLP原論文の結果ではない。比較は**文献値による位置づけ**であって、同条件の厳密な順位ではない。

ChemoMAE自身の`w/o pretraining`条件は計画に含めない。したがってSMAEの`w/o pretraining`
77.80%を上回っても、ChemoMAEに対する事前学習の因果的な利得とは解釈しない。
Table 5から言えるのは、**事前学習済みChemoMAEがこの分類課題の各isolate 100件の学習条件でどの程度の
test精度に達したか**である。採用設定のseed間ばらつきとM00/M11の両条件の値を示し、
高い平均だけで頑健性を主張しない。
M11−M00がseedを通じて一貫していれば、共通選択された分類条件における事前学習時の
TGN/FS併用の寄与を探索的に考察し、
不揃いなら平均差だけで効果を断定しない。分類設定はM11のCVで選ぶため、
この差をM00に最適な設定との比較とは扱わない。

## 既報値の位置づけと付録での説明

SMAE Table 4・5の値は**出版論文に掲載された報告値**として引用する。
数値が誤りであると示す証拠はなく、著者の理解・意図・不適切な選択を推測して論文に書かない。
ただし公開情報だけではChemoMAEと完全に同一の評価条件を確認できないため、
この比較を再実行済みの統一ベンチマーク、厳密な性能順位、SOTAの根拠とは扱わない。
確認元は[SMAE出版版](https://doi.org/10.1016/j.eswa.2025.128576)、
[RamanCluster](https://doi.org/10.1016/j.talanta.2024.126076)、
[SMAE公開コードの固定版](https://github.com/pengjuRen99/SpectraMAENet/tree/7939f2e6d3e6e975b687e4f07e56b9ce51cae5e3)とする。
本文の表注には「既存手法は文献値で再実行していない」「前処理・分割・学習・選択条件の
完全な一致は確認できない」を簡潔に記し、次の具体的な根拠は付録の評価条件欄に置く。

- **Table 4**：SMAE以外の既存5手法の30数値中29数値がRamanCluster Table 1と一致する。
  既報値を踏襲した可能性はあるが、SMAEが再実行したか否かは確定しない。
  Bacteria-6の対象IDは資料間で一致せず、SMAE Table 4の実際のID・分割indexは不明である。
  引用行は点推定値のみでseed別値がない。ChemoMAEの5 seed標本SDを併記しても、
  既報手法の変動や統計的優越性を推定しない。
- **Table 5**：出版本文は事前学習後のencoder更新を述べる一方、確認した公開コードの
  `--linear_probing`既定値ではencoderを凍結する。報告値を生成した実際の更新範囲、
  checkpoint選択、反復の開始点、95%信頼区間の計算式は特定できない。
  Fig. 10はmask率・epoch・patch size・encoder/decoder block数を変えた
  `Finetune Acc`を示し、50% maskの83.90%はTable 5のSMAE値と一致する。
  しかし図の各点をvalidationとtestのどちらで評価したか、最終設定をいつ固定したかは
  明記されていない。したがって、複数条件をtestで比較して最良値を選んだ可能性は
  排除できず、Table 5の83.90%を選択に一切用いなかった独立testの推定値として
  扱えるか確認できない。一方、test選択やリーケージが実際に起きたとは断定しない。
  TCLP行はTCLP原論文の値ではなく、SMAE著者がencoderを変更して報告した値である。
- **本研究側**：ChemoMAEはSNV、WoodDegradationMap由来の事前学習、M11の5-fold CVで
  完了した64設定のうち先頭60設定による選択を用い、採用設定だけをM00/M11の
  全件学習とtest採点へ進めた。
  既報手法と同一の前処理・探索予算を保証せず、文献値との大小は
  補助的な数値比較に留める。

### Table 5のモデル選択に関する付録用注意

モデル構成・学習条件はtrain内のvalidation、または交差検証で選び、設定を固定した後に
保留testを最終評価へ使うのが基本である。交差検証そのものが必須なのではなく、
**testを設定選択から分離すること**が要点となる。SMAE出版版はFig. 10の評価subsetと
Table 5へ至る選択順序を明示せず、公開コードで確認できるfinetune subsetの
`StratifiedKFold`も最初の1分割を使用するため、Fig. 10の探索に交差検証を用いた
証拠とはならない。もしFig. 10の各点がtest Accuracyなら、複数条件のtest値を見て
設定を選んだことになり、Table 5の選択後の値には楽観的な偏りが生じ得る。
報告された5反復の95%信頼区間も、このような設定選択の偏りを補正するものではない。
実際の選択にtestを使ったかどうかは公開情報では確定できないため、著者の行為や意図を
断定せず、**独立した最終testとして検証できないことを比較上の制約**として明示する。

付録の記述例：
「比較対象の値はRen et al. (2025) Tables 4–5から引用し、本研究では再実行していない。
Table 4の既存手法の値はRamanClusterの報告値とほぼ一致するが、再実行の有無および
Bacteria-6の実際の対象ID・分割は確認できない。Table 5について、SMAEのFig. 10は
複数の設計条件に対するfine-tuning Accuracyを示し、その83.90%はTable 5の値と一致する。
しかしFig. 10の評価集合および設定選択と最終testの順序は明記されていない。
設計条件の選択にtestを用いた場合、Table 5の値は選択による楽観的な偏りを含み得るが、
公開情報から実際の手順は確定できない。また、encoder更新範囲やcheckpoint選択等の
実行条件も特定できない。本研究のChemoMAE値は記載した独自の前処理・学習・評価条件による
実測値であり、引用値との差を厳密な同条件下の優劣とは解釈しない。」

この留保は引用値の真偽を判定するものではない。本補助実験の中心は、Table 4では
ChemoMAE自身の教師なし表現とM00/M11差、Table 5では各isolate 100件の学習ラベルによる下流適応を
独自の反復・ばらつきとともに評価することに置く。

## 局所測定から面への展開との関係

**本研究で行うこと**は、教師なしで得た古材NIR-HSIマップの領域を、同じ試料のNIRスペクトルと
位置対応FT-IRの局所所見から解釈することである。FT-IR所見を分類headの学習ラベルに使う計画ではない。

**将来の展開**として、位置が対応した局所測定から化学指標や別途実測した物性値のラベルを得られれば、
事前学習済みChemoMAEをそのラベルでfine-tuningし、NIR-HSIの各画素・領域へ予測値を配置した
面推定を検討できる。Table 5は別のRaman分類課題で下流適応を調べた補助結果として、
分類成績が下流適応を支持する場合に、局所測定由来のラベルを空間mapへ展開する
**可能性を示唆する**にとどめる。
木材物性の予測精度やmapの信頼性を今回の分類精度から推定しない。
FT-IRスペクトルそのものを物性値の真値とは扱わない。位置ずれ・測定領域や深さの違いを記録し、
訓練に使わない部位・試料で予測を検証する必要がある。局所ラベルを訓練に使った場合、同じ測定を
独立した検証にも用いない。fine-tuning後の面推定の空間的一貫性は現在の教師なしマップのLLAから
引き継げないため、別に確かめる。この将来構想を今回の実験済み成果とは記述しない。

## 執筆時の確認

1. [Table 4](../outputs/experiments/bacteria_id_table4_80_20_v1/table4.md)・
   [Table 5](../outputs/experiments/bacteria_id_table5_hpo_cv_v1/table5.md)を、seed別の値・分割・checkpoint・集計式と照合する。
2. 表注で本研究の実測値とSMAEからの引用値、両者の条件差、Table 4のSDとTable 5のCI、
   Table 5のM11 5-fold CVによる共通設定選択を明記する。
   付録には上記の比較可能性の留保と、探索のfold別validation結果を載せる。
3. Table 4は識別的な自己教師あり表現、Table 5は各isolate 100件での下流適応として別々に結論を述べる。
   Table 5の分類成績が下流適応を支持する場合のみ、局所ラベルを空間mapへ展開する可能性を示唆する。
   古材LLA・位置対応FT-IRが示す事実と役割を区別し、未確認の機構や物性マップの性能へ飛躍しない。
4. 本文に採用する数値・表現を主表と照合する。補助実験を主研究のFT-IR・空間マップに代わる証拠とはしない。

この計画は追加モデル・scratch条件を加えない。Table 5の分類学習は固定した探索空間で
HPOを行うが、`k`だけを動かす統制比較図は作成しない。
