# Preprocessing Specification

## 1. Scope

This document defines the production preprocessing of 200 Hz NIR-HSI data for downstream analysis and visualization.
The same preprocessing is used for all specimens and experiments; it is not changed in response to cross-validation or model results.

In this document, “raw SNV” refers to the baseline that directly uses the 256-dimensional SNV spectra generated by
this preprocessing, without representation learning. It does not mean raw sensor intensities.

## 2. Fixed Specification

| Item | Specification |
| --- | --- |
| Input | 200 Hz HSI and the corresponding 200 Hz white/dark references |
| Input shape | Specimen-dependent height, width of 320 px, 256 bands |
| Mask score | Sum of all 256 bands of the 200 Hz raw intensities |
| Binarization | Union of classes 1 and 2 from specimen-specific 3-class Multi-Otsu |
| Mask postprocessing | Erosion radius 1, followed by minimum object size 1 and connectivity 2 |
| Reflectance | Conversion using column-specific white/dark references |
| Wavelength cutoff | Automatic removal of the contiguous terminal interval with a reference-derived SNR proxy of 10 or less |
| Interpolation | Linear interpolation to 256 equally spaced points within the retained wavelength range |
| Normalization | Pixel-wise SNV after interpolation, using the sample standard deviation with `ddof=1` |
| Negative reflectance | Exclude the entire pixel as analytical background if any interpolated band is below 0 before SNV |
| Numeric type | `float32` for storage |
| Additional processing | No clipping, smoothing, differentiation, baseline correction, or extrapolation |
| Spectral source | 200 Hz only; no 030/200 Hz fusion |

With `min_object_size=1`, no additional small regions are effectively removed, but the processing order in Section 5.2 is fixed.

## 3. Input Contract

The production CLI uses the following files in `data/raw/`:

- `200hz_<sample_id>.hdr` and `200hz_<sample_id>.raw`
- `200hz_white.hdr` and `200hz_white.raw`
- `200hz_dark.hdr` and `200hz_dark.raw`

`<sample_id>` follows the `KYOw...` format. Production preprocessing does not require 030 Hz HSI or RGB images.
Raw data are treated as originals and must not be modified, renamed, moved, or overwritten.

Validate the following before processing:

- Correspondence between each header and raw file, and the raw byte count
- Three-dimensional HSI with positive height, width 320, and 256 bands
- No duplicate specimen IDs
- White/dark references of shape $`1 \times 320 \times 256`$
- Matching wavelength axes and `x start` across white, dark, and all specimens
- Finite, strictly increasing wavelengths

Image heights may differ between specimens. Since only 200 Hz data are used, no cropping to a common height with
030 Hz data or image registration is performed.

## 4. CLI and Output Locations

The CLI is `scripts/preprocess/run_production_preprocessing.py`.
Execution steps and pixel-count checks are described in the [runbook](../experiment_runbook.md#input-preparation).
The default output locations are `data/processed/production_v1/` for analysis data and `outputs/preprocessing/production_v1/` for inspection figures.
Both output directories must be new or empty. Only input/output locations and the chunk size for memory management
can be changed through the CLI. Fixed values such as the SNR threshold, mask settings, and number of interpolation points are not exposed as options.

## 5. Processing Steps

### 5.1 Automatic Cutoff from the 200 Hz References

For column $`x`$ and band $`b`$, define the difference between white and dark as

```math
Q_b(x) = W_{200}(x,b) - D_{200}(x,b)
```

and the band-specific reference-derived SNR proxy as

```math
\mathop{\mathrm{SNR}}\nolimits^{\mathrm{ref}}_{200}(b)
=
\frac{\mathop{\mathrm{mean}}\nolimits_x Q_b(x)}
{\mathop{\mathrm{std}}\nolimits_{x,\mathrm{ddof}=0} Q_b(x)+\varepsilon},
\qquad \varepsilon=10^{-12}
```

This is a proxy for denominator stability relative to variation across reference columns, rather than
a temporal SNR estimated from repeated acquisitions.

Define the low-SNR flag as

```math
L_b =
\begin{cases}
1, & \mathop{\mathrm{SNR}}\nolimits^{\mathrm{ref}}_{200}(b) \le 10
     \text{ or non-finite} \\
0, & \text{otherwise}
\end{cases}
```

Remove the contiguous interval with $`L_b=1`$ that extends through the final band, retaining the bands before it.
If any band before that terminal interval also has $`L_b=1`$, fail immediately because a single upper cutoff cannot represent the exclusions.
Specimen spectra, degradation information, CV results, and model results are not used to determine the cutoff.

The current references automatically select:

- Retained: bands 0–221, 913.10–2305.59 nm, 222 bands
- Excluded: bands 222–255, 2311.85–2518.47 nm, 34 bands
- Plotted boundary: midpoint between bands 221 and 222, 2308.72 nm

Do not hard-code these band indices or wavelengths into the processing code. Recalculate them from the references at runtime and save them.

### 5.2 Wood-Region Mask

Let $`I_{200}`$ be the 200 Hz raw-intensity cube. Define the score of each pixel as

```math
A(y,x) = \sum_{b=0}^{255} I_{200}(y,x,b)
```

Reflectance, SNV, 030 Hz data, and RGB images are not used to generate the mask.

Apply 3-class Multi-Otsu to $`A(y,x)`$ separately for each specimen, assigning classes 0, 1, and 2 in intensity order.
Class 0 is the background candidate, and the union of classes 1 and 2 is the wood candidate. Class names indicate intensity order only;
they do not represent wood tissue or degradation classes.

Apply morphological processing to the wood candidate in this order:

1. Binary erosion with a disk of radius 1
2. Small-object removal with `min_object_size=1` and `connectivity=2`, corresponding to an 8-connected neighborhood

Do not apply unspecified shape changes such as hole filling, closing, or retaining only the largest connected component.
Retain the mask after morphological processing and the original image coordinates of pixels within it.

### 5.3 Reflectance Conversion

Convert specimen intensity $`I_{200}`$ using the white and dark references at the same column $`x`$:

```math
R(y,x,b)
=
\frac{I_{200}(y,x,b)-D_{200}(x,b)}
{W_{200}(x,b)-D_{200}(x,b)}
```

Broadcast the references along specimen rows while retaining their column-specific information.
Do not replace them with a single spatially averaged reference spectrum.

If the denominator is nonpositive or non-finite, set the corresponding reflectance to a non-finite value. Do not add `eps`
or clip reflectance to `[0,1]`. Negative values after interpolation are treated as background according to Section 5.5.
Pixels with values above 1 are recorded in the quality statistics but are not excluded on that basis alone.

### 5.4 Valid-Pixel Selection

Within the morphological mask, select pixels for which all retained bands after cutoff are finite.
Exclude any pixel containing a non-finite value from the spectra used for analysis, saving its original coordinates and reason code 1.
Keep the morphological mask unchanged and separately save the region remaining after quality filtering as `valid_spectrum_mask`.

### 5.5 Linear Interpolation to 256 Points

Let the measured wavelengths after cutoff be $`\lambda_0,\ldots,\lambda_{C_s-1}`$. Define the output wavelengths as

```math
\tilde{\lambda}_j
=
\lambda_0
+ \frac{j}{255}\left(\lambda_{C_s-1}-\lambda_0\right),
\qquad j=0,\ldots,255
```

Use linear interpolation between the two measured bands bracketing each $`\tilde{\lambda}_j`$.
Restrict interpolation to the closed interval of retained wavelengths; do not apply extrapolation, higher-order interpolation, or smoothing.

For the current input, 222 points are interpolated to 256 points within 913.10–2305.59 nm and subsequently treated as $`16 \times 16`$ patches.

Exclude pixels whose sample standard deviation after interpolation is non-finite or nonpositive, since SNV is undefined for them, and save reason code 2.

Among the remaining pixels, exclude the entire pixel if any of its 256 interpolated reflectance bands is strictly below 0, and save reason code 3.
When exclusion reasons overlap, prioritize codes 1, 2, and 3 in that order. A zero-valued band alone is not a reason for exclusion, and negative values are not replaced with 0.
This rule does not apply to negative values produced by SNV.

Set `valid_spectrum_mask=0` for these pixels and omit them from the sparse `reflectance`, `snv`, and `pixel_row_col` arrays.
Downstream, they receive background label 0 and are consistently excluded from candidate pixels for training sampling, all valid test pixels, and metric denominators.
Display them transparently in spatial diagnostic figures. Retain the original morphological `mask` as a diagnostic record,
and use `excluded_pixel_row_col` and reason codes to trace the locations reassigned to background.

### 5.6 SNV

Let $`r_p(b)`$ denote the valid 256-dimensional reflectance after interpolation. For each pixel $`p`$, calculate

```math
\mu_p = \frac{1}{C}\sum_{b=1}^{C} r_p(b),
\qquad C=256
```

```math
s_p
=
\sqrt{
\frac{1}{C-1}
\sum_{b=1}^{C}\left(r_p(b)-\mu_p\right)^2
}
```

and define SNV as

```math
z_p(b) = \frac{r_p(b)-\mu_p}{s_p}
```

Because the sample standard deviation is used, up to numerical error,

```math
\frac{1}{C}\sum_{b=1}^{C}z_p(b)=0,
\qquad
\mathop{\mathrm{std}}\nolimits_{\mathrm{ddof}=1}\!\left(z_p\right)=1,
\qquad
\lVert z_p\rVert_2=\sqrt{255}
```

Record the maximum numerical deviation from these invariants at runtime.

### 5.7 Reflectance L2-Norm Map

Construct the map for spatial inspection from reflectance after interpolation to 256 points and before SNV:

```math
M_{L2}(y,x)
=
\sqrt{\sum_{b=1}^{256}\widetilde{R}(y,x,b)^2}
```

Do not use the post-SNV L2 norm for this map, since it is approximately $`\sqrt{255}`$ for every valid pixel.
Set pixels excluded by quality filtering and background pixels to non-finite values and display them transparently.

## 6. Storage Format

Separate analysis data from inspection visualizations.

```text
data/processed/production_v1/
  config.json
  cutoff_decision.json
  preprocessing_summary.json
  manifest.parquet
  reference_band_quality.parquet
  wavelength_grid.parquet
  mask_quality.parquet
  mask_components.parquet
  sample_quality.parquet
  source_band_statistics.parquet
  source_band_summary.parquet
  output_band_statistics.parquet
  output_band_summary.parquet
  ranked_final_snv_spectra.parquet
  samples/
    <sample_id>.h5

outputs/preprocessing/production_v1/
  report_config.json
  cutoff_decision.png
  interpolated_reflectance_band_distribution.png
  interpolated_snv_band_distribution.png
  final_snv_anomaly_candidates.png
  reflectance_l2_norm/
    <sample_id>.png
```

Store data for downstream analysis, quality tables, coordinates, and the fixed configuration in `data/processed/`.
Store figures for human inspection and their rendering settings in `outputs/preprocessing/`.
Do not use artifacts from exploratory runs as inputs to production preprocessing.

### 6.1 Specimen HDF5 Schema

Each `<sample_id>.h5` contains at least the following:

| Dataset / attribute | Contents |
| --- | --- |
| `wavelength_nm` | Vector of 256 wavelengths after interpolation |
| `source_wavelength_nm` | Vector of measured wavelengths after cutoff and before interpolation |
| `retained_source_band_index` | Retained original band indices |
| `mask` | Two-dimensional wood mask after morphological processing |
| `valid_spectrum_mask` | Two-dimensional valid-pixel mask after quality filtering |
| `pixel_row_col` | Original image coordinates corresponding to each row of `reflectance` and `snv` |
| `excluded_pixel_row_col` | Original image coordinates of masked pixels excluded by quality filtering |
| `excluded_reason_code` | Exclusion reason: 1 for non-finite reflectance, 2 for a nonpositive or non-finite standard deviation of the SNV input, and 3 for negative interpolated reflectance |
| `reflectance` | Valid-pixel reflectance after interpolation to 256 points and before SNV |
| `snv` | 256-dimensional SNV |
| `reflectance_l2_norm` | Two-dimensional map with non-finite values for background and invalid pixels |
| Attributes | Schema version, specimen ID, source files, original shape, pixel counts, SNR threshold, and SNV definition |

Use `float32`, gzip level 4, shuffle, and chunking along the pixel dimension in HDF5, with one file per specimen.
Keep valid-pixel spectra aligned with coordinates, masks, wavelengths, and metadata, allowing individual datasets or chunks to be read as needed.
Do not duplicate the full three-dimensional reflectance cube.
The production_v1 storage schema is version 2 and includes reason code 3 and the corresponding quality-summary columns.
Identify inputs using the preprocessing ID and the configuration field `negative_reflectance_policy`.
`negative_interpolated_reflectance_excluded_pixel_count` is the number of pixels excluded under code 3.
`pixels_with_any_negative_interpolated_reflectance` is the number of negative-valued pixels included in storage; it is 0 under this quality policy.

The compression ratio depends on the reflectance distribution. Save each specimen's actual file size in `manifest.parquet`,
along with the size required to store reflectance and SNV as uncompressed `float32`.
Save totals across all specimens and their ratio in `preprocessing_summary.json`.

## 7. Quality Checks

### 7.1 Machine-Readable Checks

- `cutoff_decision.json`: Automatically selected retained/excluded bands, wavelengths, and boundary
- `reference_band_quality.parquet`: SNR proxies and retention flags for all 256 bands
- `mask_quality.parquet`: Multi-Otsu thresholds, class pixel counts, and pixel counts before and after morphological processing
- `sample_quality.parquet`: Exclusion counts, out-of-range reflectance, SNV shape metrics, and numerical invariants
- `output_band_summary.parquet`: Band-wise distributions of interpolated reflectance and SNV
- `preprocessing_summary.json`: Total pixel counts, exclusion rates, HDF5 sizes, and SNV numerical errors

### 7.2 Inspection Visualizations

- `cutoff_decision.png`: A single panel showing the reference-derived SNR proxy, fixed threshold, retained/excluded ranges, and cutoff boundary
- `interpolated_reflectance_band_distribution.png`: Band-wise distribution of interpolated reflectance
- `interpolated_snv_band_distribution.png`: Band-wise distribution of final SNV
- `final_snv_anomaly_candidates.png`: SNV spectra for the top 20 pixels with the largest maximum second differences, in individual panels arranged in 5 rows × 4 columns
- `reflectance_l2_norm/<sample_id>.png`: Spatial distribution of reflectance intensity in the wood region

`final_snv_anomaly_candidates.png` ranks candidate pixels by the maximum second difference in the final SNV spectra,
showing one pixel's SNV spectrum as an orange line in each panel. A black line shows the across-specimen median of the specimen-specific median at each band;
a band shows the across-specimen medians of the specimen-specific 1st and 99th percentiles as a common reference.
Annotate each panel with the rank, specimen ID, and pixel coordinates. Mark values outside the displayed vertical range with triangles at the upper or lower edge,
and report the actual minimum and maximum for that candidate.
Explain the out-of-range triangles in the text rather than the legend.
This is a ranked plot for inspecting individual spike candidates, not a measure of anomaly prevalence.
Do not exclude additional pixels based solely on their rank.

## 8. Visualization Conventions

Follow the [shared figure conventions](visualization_and_interpretation.md#figure-style) and omit figure titles and axes titles.
Describe preprocessing figures, settings, and panels in captions or filenames.
Annotate individual candidate-pixel panels with the rank, specimen ID, and pixel coordinates for traceability.

Use consistent vertical axes for the spectra: `[0, 1]` with tick spacing `0.2` for reflectance, and `[-2, 2]` with tick spacing `0.5` for SNV.
These are display-range conventions, not clipping of preprocessed values or changes to quality criteria.
For the horizontal axis, follow the shared figure conventions: show both wavelength endpoints to two decimal places,
place interior ticks every 200 nm starting at 1000 nm, and add no padding beyond the data range.
Keep a logarithmic SNR-proxy axis in `cutoff_decision.png`; do not add lower panels for specimen spectral spread or outlier rates.

Use the following settings consistently for reflectance L2-norm maps:

- Colormap: `plasma`
- Transparent background
- Shared `vmin` and `vmax` set to the 1st and 99th percentiles of pooled finite values within all specimen masks
- No specimen-specific autoscaling
- No colorbar
- Display clipping must not change stored values

## 9. Rationale for the Adopted Procedure

- Although 030 Hz data can supplement the long-wavelength signal, they saturate at shorter wavelengths.
  The 200 Hz-only configuration was adopted to avoid artificial steps or curvature from joining spectral sources.
- Instability at the long-wavelength end of the 200 Hz data can be removed using a terminal cutoff based on reference SNR,
  independent of specimen or model results.
- Binarization using reflectance L2 norms omitted some latewood, so 3-class Multi-Otsu on the sum of 200 Hz raw intensities was adopted for the mask.

Alternative procedures must preserve existing runs and be treated as separate specifications with a new research decision and preprocessing ID.
