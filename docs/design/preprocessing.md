# 前処理設計

## 1. ステータス

**Open**

前処理は、実験開始前に確定する最後の研究設計項目である。
本書は未決定事項を他の確定設計から分離するためのplaceholderとする。

## 2. 確定している境界条件

- ENVI形式のスペクトルデータは`spectral.io.envi`で読み取る。
- 試料IDはファイル名の`KYOw...`とmetadataの`KYOw`を対応付ける。
- rawデータは変更、改名、上書きしない。
- 実験へ渡す各画素スペクトル、波長vector、木材領域maskの対応を保持する。
- 主比較の入力表現B0は、最終的に確定した前処理後のSNVスペクトルとする。
- すべての比較条件へ同一の前処理を適用する。

## 3. 参考実装として確認済みの処理

過去実装には次の処理が含まれるが、現時点では最終仕様とみなさない。

- dark/white/sample cubeのENVI読み込み
- $R=(I-D)/(W-D)$による反射率化
- wavelength metadataの取得
- L2 norm mapとOtsu法による木材領域mask
- 画素スペクトル単位のSNV

特に木材領域の二値化は、過去コードのコメントどおり強度ベースへ変更する可能性がある。

## 4. 確定が必要な事項

- 030 Hzと200 Hzを別々に扱うか、片方を使用するか、統合するか
- 両測定間の位置対応を仮定できるか
- 使用波長範囲、band除外、resamplingの有無
- dark/white referenceの対応規則と反射率計算の詳細
- 木材領域maskの生成方法
- 異常値、NaN、Inf、飽和画素の扱い
- SNVを適用する位置と、追加の前処理を行うか
- 大規模cubeを一括保持しないためのchunkingおよび保存形式

これらは実験条件間で共通に固定し、CV結果を見て変更しない。
