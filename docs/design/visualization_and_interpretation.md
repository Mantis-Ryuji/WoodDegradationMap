### 1.2 全体fitの入力と表現

全49試料のそれぞれから、実験プロトコルと同じ$q=8192$画素を一様ランダム・非復元抽出する。
全条件で同じ抽出座標を共有し、抽出画素を全試料でまとめた集合を使ってPCA・ChemoMAEの
fitまたは学習を行う。得られた各条件の表現にCosine-KMeansをfitする。
fit後はモデルを固定して全試料の全有効画素へ推論し、マップとスペクトルの要約を作成する。
試料ごとのクラスタリング再fitは行わない。
全体学習用の抽出seedと座標manifestも保存する。fitに用いる試料は全試料だが、fit画素と表示画素は区別する。
表現・全可視抽出・精度は[CVと同じ仕様](experiment_protocol.md#representations)を使用する。
表示用の2次元投影はクラスタリング後の補助表示とし、元の表現に代えてクラスタリングへ入力しない。

## 3. 観測SNV代表スペクトルによるHungarian matching

<a id="matching-reference"></a>

### 3.1 基準条件

M00（追加augmentationなしの標準MAE）の表現をCosine-KMeansで分割したpartitionを、全5条件の表示番号の共通基準とする。
B0・B1・A0・M11の4条件を、それぞれ独立にこの基準へ直接matchingする。

標準MAEを比較の起点とし、M00からM11への領域分割の変化を読むための表示基準とする。
M00の安定性が最良と確認されたことを採用理由にはせず、劣化検出性能・解釈可能性やクラスタの順序も保証しない。
[OOF sanityのfold内B0基準](oof_sanity_visualization.md#3-fold内hungarian-matching)は別の表示規約である。

試料ごとのmatching、および別の条件を経由する連鎖matchingは行わない。
B0・B1間だけ一致画素数に基づく別方式を使わず、全5条件に同じ規約を適用する。

### 3.2 観測SNV代表線のcosine類似度

全試料について比較対象に共通して有効な木材画素だけを使用し、全5条件で同じ画素座標を共有する。
2026-09-20の最新ユーザー指定により、matchingは観測SNV代表線のcosine類似度で行う。
画素は試料ID・座標の組で識別し、hard labelの所属を固定する。
保存済み画素別SNVを試料・クラスタ内で算術平均し、クラスタが存在する試料の平均線を等重みで平均する。
この代表線は第4.1節のSNV図と同じもので、平均反射率へ改めてSNVを適用しない。
基準クラスタの代表線を$\boldsymbol{s}_i$、比較対象の代表線を$\boldsymbol{t}_j$として、
全256バンドを使用した8×8の行列を作る。

$$
S_{ij}=\frac{\boldsymbol{s}_i^{\mathsf T}\boldsymbol{t}_j}
{\lVert\boldsymbol{s}_i\rVert_2\lVert\boldsymbol{t}_j\rVert_2}
$$

代表線をL2正規化して内積を取り、符号を保った類似度（−1〜1）を使用する。
画素数による試料の重み付け、代表線の波長方向の再標準化、帯域選択は行わない。
背景0は行列・割当から除外する。全試料を通して空のクラスタ、非有限またはノルム0の代表線があれば、
条件・元クラスタ番号を示して停止する。試料内に存在しないクラスタの曲線は平均から除き、0で補完しない。
潜在ベクトル、反射率、疑似吸光度、二次微分、metadataおよびIoUは割当の目的関数に含めない。

Hungarian assignmentにより、SNVのcosine類似度の合計を最大にする。

$$
\max_{\pi}\sum_{i=1}^{K_0}S_{i,\pi(i)}
$$

この1対1対応$\pi$を比較対象ごとに求め、比較対象のクラスタ$\pi(i)$を表示番号$i$へ置換する。
クラスタ所属、学習済みモデル、クラスタリング中心は変更しない。

### 3.3 対応の確認用contingency・overlap

同じ共通有効画素について、基準と比較対象のhard labelからcontingency matrixも求める。

$$
C_{ij}
=\sum_p\mathbf{1}[y_p^{(\mathrm{ref})}=i\land y_p^{(c)}=j]
$$

SNVのcosine類似度行列全体、選ばれた対応とその類似度、同じ基準クラスタに対する他候補との類似度差を保存する。
IoU行列、contingency matrix、および対応後の一致画素数・overlapはCSVの補助値として保存する。
IoUは$C_{ij}/(\sum_\ell C_{i\ell}+\sum_\ell C_{\ell j}-C_{ij})$で計算する。
IoUと一致画素数は割当には使わず、スペクトルで対応づけたクラスタの空間的な重なりを確認する。
全体のoverlapは$\sum_i C_{i,\pi(i)}/\sum_{i,j}C_{ij}$とし、全共通画素数に基づくため大きい試料の寄与が大きいことを明記する。

類似度が低い対応や候補間の類似度が拮抗する対応を明示し、同じ色だけで強い対応と解釈しない。
同率の最適割当を一意の対応根拠とはみなさない。SNV類似度が低くても1対1の割当は成立し得る。
クラスタの分割・統合の違いは行列全体で確認し、同一表示番号を化学的な同一性の保証としない。
SNVの近さは割当の基準そのものであり、独立した化学的検証とは呼ばない。
反射率・疑似吸光度・二次微分も併読する。方式変更前の表示番号と比較する際は元クラスタ番号を照合する。

### 3.4 適用範囲

得られた対応は全試料で共通とし、次へ一貫して適用する。

- label mapの色と番号
- cluster sizeおよびoccupancy
- 代表スペクトルと差スペクトル
- cluster別の補助統計

元のクラスタ番号と表示番号の対応を保存する。
matchingは表示と対応関係の確認を目的とし、異なる条件のクラスタが同一の意味を持つことを保証しない。
類似度行列とcontingency・overlapを併記し、対応の弱いクラスタを可視化上の同一色だけで解釈しない。
表示ラベルの整列として用い、CV指標の計算や共通基準を正解とした精度評価には転用しない。

条件間の比較には、本番前処理HDF5の`pixel_row_col`で同一と確認できる画素だけを使用する。
条件ごとに画素集合を変更したり、label mapを位置補正したりしない。

### 4.1 スペクトルの表示と要約

代表スペクトルは試料内平均→試料間の等重み平均で集計する。
スペクトルは第3節のSNV cosine matching後の表示番号で比較する。SNV代表線だけをmatchingに使用する。
比較する代表線は反射率、SNVおよび疑似吸光度の二次微分の3種類とする。

全試料の代表線は条件間の概観とmatchingに使う。個別試料の領域差を解釈する際は、
既存の試料別クラスタ平均と画素数・除外数を参照する。全試料macro平均で局所的な差が薄まる可能性と、
構成試料がクラスタごとに異なる点を区別して読む。試料間IQRを単一試料内のばらつきとして転用しない。
M11・K8の試料別詳細PNGは対象・構成を未確定とし、執筆で必要な根拠を絞ってから定める。

#### 入力と変換順序

- 各条件のhard labelによるクラスタ所属を固定し、同じ本番前処理データの全有効画素を起点とする。
  代表線は所属画素の観測スペクトルから作り、潜在クラスタ中心、PCA逆変換、decoder再構成から合成しない。
- 反射率には補間後の256帯域、SNVには既存の画素別SNVを用いる。
- 疑似吸光度は各画素の反射率 $R_p(\lambda)$ から $A_p(\lambda)=-\log_{10}R_p(\lambda)$ として求める。
  SNVを対数変換せず、平均反射率にSNVや対数変換を適用して代用しない。
- 疑似吸光度とその二次微分の集計対象は、全256帯域の反射率が正かつ有限の画素に限る。
  1帯域でも条件を満たさない画素は、そのスペクトル全体を当該集計から除外する。微小値への置換やclipは行わない。
  この除外は疑似吸光度解析に限り、反射率・SNVの集計、SNVによるmatching、学習・CV・クラスタ所属は変更しない。
  条件・手法間で同じ反射率の有効性判定を適用する。

#### 2段階の平均とばらつき

- 反射率、画素別SNVおよび画素別疑似吸光度について、試料・クラスタごとに所属する集計対象画素をband別に算術平均する。
- 次に、集計対象画素が残る試料の平均線をband別に等重みで算術平均し、全体の代表線とする。
  全画素を直接poolせず、試料ごとの画素数の違いによる偏りを抑える。
- クラスタが存在しない試料、および疑似吸光度の除外後に対象画素がなくなった試料・クラスタは、
  対応する代表線の集約対象に含めない。0や他のスペクトルで補完せず、寄与試料がない代表線は未定義とする。
- 試料間のばらつきは、試料別平均線のband別四分位範囲で示す。二次微分については、各試料の平均疑似吸光度に
  下記のSG処理を施してから試料間の四分位範囲を求める。四分位点の曲線を微分して代用しない。
- 代表線ごとに寄与試料数・試料ID・画素数を示す。疑似吸光度・二次微分では除外後の数を用い、
  除外画素数も記録する。代表線の種類やクラスタによって構成試料・画素が異なり得ることを明示する。
- 1試料だけが寄与する場合は試料間のばらつきを評価できないと記す。平均代表線は実在する1画素の
  スペクトルや成分濃度の推定値を意味しない。

#### 疑似吸光度のSG二次微分

疑似吸光度の全体平均線にSciPyの `scipy.signal.savgol_filter` を適用し、波長（nm）に対する二次微分を求める。
設定は次のとおりとし、試料別平均線から四分位範囲を求める際にも共用する。

| 引数 | 設定 |
| --- | --- |
| `window_length` | `7` |
| `polyorder` | `2` |
| `deriv` | `2` |
| `delta` | 保存された等間隔の波長gridの隣接差（nm）。既定値1には置き換えない |
| `axis` | 波長を最終軸とし、既定値 `-1` |
| `mode` | 既定値 `"interp"` |
| その他 | SciPyの既定値 |

端点では先頭・末尾の7点への2次多項式近似から微分値を求める。二次微分の単位は $\mathrm{nm}^{-2}$ とする。
平均と固定設定のSG処理は線形なので、同じ対象・重み・波長grid・端点処理なら、試料別平均線を微分してから
試料間平均しても代表線は一致する（丸め誤差を除く）。SNV・対数変換と平均の順序は入れ替えない。
SGを適用する対象は疑似吸光度の二次微分とし、反射率・SNVは上記の平均代表線を比較する。

#### 比較と解釈

- 3種類の代表線を条件・クラスタ間で比較し、差が現れる波長帯を調べる。
  M00のCosine-KMeansへのHungarian matchingには第3節のSNV代表線のcosine類似度を使う。
  二次微分や特定帯域を見て対応を手動変更しない。
- difference spectraは同じ種類の代表線どうしの差とし、差を取る条件・クラスタと引き算の向きを記す。
  別々の構成試料から作った代表線の差を、同一試料のpairedな化学変化とは解釈しない。
- SNVでは画素ごとのoffsetとscaleを除いているため、SNV振幅差を吸収量や成分量の直接比較に使わない。

### 4.3 PCA・連続スペクトル指標map・観測スペクトルの対応

2026-09-20のユーザー指定により、全体fit後の探索的解析では、表現空間・試料表面・観測スペクトルの
対応を重点的に調べる。出力図は論文用の静的なPNGとし、表と図の元数値はCSVで保存する。
密度・Cluster IDのPCA一枚は生成済みである。追加色分け・連続指標map・対応詳細図は候補として保持し、
執筆で必要性を確認してから実施範囲を選ぶ。帯域・平滑化・積分の未確定値を既定値で補って実装しない。
5条件で比較する場合の共通座標・色値の規約を以下に示す。

#### 比較対象とPCA

- B0・B1・A0・M00・M11の5条件を対象とする。B0・A0・M00・M11はクラスタリングに使う正規化済み表現を
  中心化したPCAで2次元へ投影する。B1は保存済みbaseline PCAの上位2成分の未正規化得点を直接使う。
  B0は入力SNV表現、B1はPCA表現であり、全条件をNN潜在とは呼ばない。
- 同じ試料・画素座標の集合を5条件で共有する。可視化用PCAをfitするのはB1以外の4条件。同一条件では、クラスタ番号・
  試料metadata・帯域指標の色分けを変えても同じ2次元座標を再利用する。
- クラスタ番号は第3節の整列後の番号を使う。追加図を採用する場合は、試料ID・樹種などの確認済みmetadata、
  または下記の連続スペクトル指標を別々の色分けとして用いる。欠損metadataを推測で補完しない。
- 条件間でPCAの軸・向き・座標値が対応するとはみなさない。同じ画素の色・所属・観測スペクトルの
  対応を読む。クラスタリングやCV指標の計算には2次元座標を入力せず、図の分離だけで条件の優劣を決めない。
- `(B0, B1)`・`A0`・`(M00, M11)`で表現の性質が異なる可能性を探索する。これはOOF結果を見た後の
  仮説であり、確認済みの群分けや、全体fitだけでOOFのARI差を説明できるという意味ではない。

既存PCA一枚の設定は次のとおり。

| 項目 | 設定 |
| --- | --- |
| fit・表示画素 | 既存global manifestの49試料×8,192＝401,408画素すべて。同一画素を全5条件で共有 |
| 入力 | B0は256次元、A0・M00・M11は16次元のクラスタリング用FP32・L2正規化済み表現。B1は既存baselineの上位2成分のFP32未正規化得点 |
| 投影 | B1は特異値の降順に既存PCを選択。他4条件は中心化したPCAのPC1・PC2。追加の列標準化・whitening・投影後の正規化なし |
| 計算 | 他4条件は既存scikit-learn、CPU・FP64、`n_components=2, svd_solver="covariance_eigh", whiten=False`。B1は既存FP32 transformの得点をそのままFP64で保存 |
| 乱数 | PCA fitは乱数を使わない。散布点の描画順だけROOT_SEEDで固定 |
| 保存 | 座標・平均・主成分係数・固有値・寄与率・runtime・入力画素とhash。数値表はCSV |

B1は`checkpoints/baselines/pca.npz`の特異値の降順で上位2成分を選び、L2正規化前の得点をPC1・PC2とする。
同値の特異値は保存順を維持する。再fit・再中心化・軸の再回転は行わず、平均・係数・特異値・固有値・寄与率と
元成分indexを保存する。B1の寄与率は元のSNV全分散に対する保存済みの値であり、16成分や2成分内で再正規化しない。
クラスタ所属は従来の16次元L2正規化表現から得た結果をそのまま使う。
PCAは最大分散の線形投影であり、化学的に重要な変動がPC1・PC2に必ず現れるとは仮定しない。
寄与率は各条件自身の入力表現の全分散を分母とし、条件間の化学情報量の共通尺度とはしない。
実装の仕様は[scikit-learn PCA](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html)を参照する。

既存モデルの表現抽出は元のホスト環境で行い、PCA fit・描画も同じ環境で実行する。
fitは`global_pca.py`、PNG描画は`visualize_global_pca.py`へ分離する。
出力図は`results/figures/global_k8_v1/pca-latent-2d/01_pca_density_clusters.png`。
親図表とは独立して検証し、親のクラスタ図表を再生成しても`pca-latent-2d/`を保持する。

#### クラスタに依存しない連続スペクトル指標

採用する場合の処理順序は、画素別の疑似吸光度 → 空間平滑化 → SG二次微分 → 選択帯域の積分とする。
疑似吸光度の定義・有効性判定とSG設定は第4.1節を継承する。

- 空間平滑化の候補は、自分を含む3×3近傍の算術平均、またはGaussianによる重み付き平均とする。
  **同じクラスタに属する近傍だけに限定しない。** 近傍のスペクトルは概ね似るという仮定を置き、
  全条件に共通する観測疑似吸光度から一つの指標mapを作る。
- 背景と疑似吸光度を定義できない画素は平均から除き、残った近傍の重みを正規化する。
  中心画素自体が背景・無効の場合は指標を作らず、近傍値で穴埋めしない。寄与近傍数を記録する。
  Gaussianは中心付近を重くできるが、クラスタ境界をまたぐ寄与をなくす処理ではない。
- 平滑化は画像の空間方向に適用し、その後に波長方向のSG二次微分を求める。
  3×3平均とGaussianのどちらを採用するか、Gaussianの幅・打切り範囲・画像端の処理はOpenとする。
- 指標は観測スペクトルから計算し、encoder・decoder・クラスタラベルに依存させない。
  同じ画素には5条件のすべてで同じ色値を使い、同じ帯域指標のcolor scaleも共有する。
  表示範囲と範囲外の値の扱いを記録し、保存する数値は表示のためにclipしない。
- この空間平滑化は解釈用の色値と連続mapのための処理であり、モデル入力・PCA入力・クラスタ所属・
  CV指標には適用しない。第4.1節のクラスタ代表線も、従来どおり所属画素の観測スペクトルから集約する。

連続mapは量子化せずに帯域指標の分布を示せるため、ChemoMAEなしでも作成できる。
クラスタmapと併記し、連続的な変動を各partitionがどこで区切っているかを観察する。
空間平滑化した色値のまとまりを、encoderが空間構造を学んだ証拠にはしない。

#### 帯域選択と積分の定義（Open）

帯域指標を採用する場合、帯域は事前にOHなどへ固定せず、対象試料・クラスタの観測スペクトルを
確認してから選ぶ。第4.1節の試料等重み平均線・試料間四分位範囲・試料別曲線を併読し、
差が見える帯域と、ノイズや一部試料に依存して見える帯域を検討する。
OHなどへの帰属は候補であり、対象帯域と一次文献の対応を確認してから記述する。

1. 対象とする試料・条件の曲線を確認し、候補帯域の位置・幅、差が現れるクラスタ・試料、選択理由を記録する。
2. 候補ごとに積分端点（nm）と波長grid上の扱い、数値積分法、符号を含む指標定義を決める。
   二次微分の符号付き積分では正負の部分が相殺し得る。負の谷を含む区間の符号反転積分と、
   負の部分だけを積分する値は異なる指標なので、表示に都合のよい方へ暗黙に切り替えない。
3. 候補と採否の理由を残す。5条件を比較する場合は、採用した帯域・計算法・平滑化設定を共用する。
   共通定義の連続mapとPCAの色分けを作成し、元の二次微分曲線に選択区間を示して対応を確認する。

帯域数、端点、符号・積分方式、平滑化設定、color scaleの数値は未確定である。
帯域を結果から選ぶ解析として報告し、その同じデータでの対応を独立した化学的検証とは呼ばない。
積分値は選択したスペクトル特徴の指標であり、成分濃度・劣化度へ直接読み替えない。

## 5. 解釈上の制約

潜在空間と試料表面の対応に関する探索的仮説と、LLA・LFR・ARI・silhouetteを併読する際の注意は
[結果の読み方と解釈](../interpretation_notes.md)を参照する。

- label map、代表・差スペクトル、試料情報を併読し、クラスタを劣化classとは断定しない。
- A0とM00の比較は、maskの有無とloss対象（全領域・masked領域）の両方の変更を含む。
  マップやスペクトルの違いをmask率だけの効果とは解釈しない。M00とM11の比較は、
  noise・shiftを併用するaugmentation条件の違いとして読む。
- hard labelの代表スペクトルは純粋成分を意味しない。
- 吸収帯との整合性は化学的仮説の観察根拠とする。樹種・材組織・含水・測定面などの代替説明について、
  確認済みの情報と未確認の可能性を分ける。劣化機構・成分量の一意な同定や検出性能の検証とはしない。
- PCAなどの2次元投影だけで表現の優劣を決めない。
- 可視化結果を用いて主条件を入れ替えたり、best条件を事後定義したりしない。

### 5.1 位置対応FT-IRによる解釈の深化（計画あり・詳細設計Open）

HSIのクラスタが割り当てられた領域そのもの、または位置対応した領域をFT-IRで測定する予定である。
目的は、**NIRマップで分けられた領域のスペクトル差を、別モダリティの観測から化学的に解釈すること**とする。
測定方式・対象・反復・前処理・指標・位置対応は下表でOpenとして管理し、他の証拠との関係は第5.2節に整理する。

FT-IRの追加だけで全クラスタ・全画素の正解劣化ラベルが得られるわけではない。クラスタ間の化学的な
差が観測されても、それが劣化に由来するかは樹種・組織・含水・表面状態などと区別して考える。
同じ木片の別位置での測定だけではクラスタとの位置対応を支持できず、測定領域が複数クラスタを含む場合は、
単一クラスタのFT-IRスペクトルとみなさない。別モダリティの測定であることと、選定の偏りがないことも区別する。

測定・解析の前に次を確定・記録する。

| Open事項 | 決める内容・残す記録 |
| --- | --- |
| 対象と選択時点 | 対象の表現条件・クラスタリング手法・K・モデル、試料ID・領域の選択基準、選定時に見ていたNIR結果。本文の7代表試料を自動でFT-IR対象とはしない |
| 位置対応と測定体積 | NIR座標・ROIとFT-IR測定位置の対応、位置誤差、測定範囲・深さ、境界や混合領域の扱い、測定方式・試料処理による違い |
| 反復と比較単位 | 試料・領域・測定反復の関係、クラスタ内変動とクラスタ間差の比較方法、同一試料内で対応比較できる範囲。点測定数を独立試料数としない |
| 前処理と化学的根拠 | FT-IRの前処理、比較帯域・指標、帰属の一次文献、樹種などの代替説明。対象と測定条件に適した根拠を確認して指標を定める |
| 報告範囲とモデル選択 | 化学的な差が見られない例を含めた報告と、測定した領域から主張できる範囲。FT-IRを解釈に使うか、将来モデル選択にも使うかの区別 |

現行CVの条件・K・seedをFT-IRに合わせて事後変更しない。もし今後FT-IRを使ってモデルや解釈規則を
選ぶなら、その同じ測定を未使用の独立検証とは呼べないため、別の設計判断と検証計画が必要になる。
測定結果は未確認であり、化学的対応・劣化度の定量性能が確認済みとは記載しない。

<a id="evidence-triangulation"></a>

### 5.2 目視判断・教師なし評価・化学的解釈の統合

現行データには画素単位の正解劣化ラベルや、全試料の劣化を定量する独立測定がない。
そのため、マップが劣化を捉えたかは単一の指標で確定せず、次の異なる層の証拠を区別して併読する。

| 証拠の層 | 確認する問い | それだけでは支持しないこと |
| --- | --- | --- |
| 人間による目視判断 | 外観上認識できる劣化の位置・形状とラベルマップが対応するか | 画素単位の正解、劣化検出精度、化学的な原因の同定 |
| 教師なし評価・診断 | LLA（補正後）・LFR・ARI・occupancy・silhouetteにより、マップの空間的一貫性、指定摂動への安定性、反復間再現性、退化を確認できるか | その空間構造が劣化に対応すること、境界の正しさ |
| スペクトルと位置対応FT-IR | クラスタ間の観測スペクトル差が、劣化に関係する化学的解釈と整合するか | 未測定画素を含む全領域の正解ラベル、劣化機構や成分量の一意な同定 |

目視上の劣化対応、教師なし指標による安定性・一貫性、およびスペクトルまたはFT-IRの化学的所見が
同じ方向を示す場合に、「劣化に関連する可能性のある、安定した空間領域を教師なしで抽出した」範囲で記述する。
証拠間が一致しない場合は単一の総合scoreへ潰さず、例えば「指標上は安定しているが、目視上の劣化対応は確認できない」と分けて報告する。
本研究ではこれを教師ありの「AI劣化診断精度」とは呼ばず、教師なし領域分割と診断指標による確認として扱う。

正式な目視評価を行う場合は、次を結果の確認前または評価開始前に定め、記録する。

- 評価対象と提示範囲。全49試料の保存マップと第4.2節の固定7代表試料の役割を分け、良好に見える例だけを根拠にしない。
- 評価者、評価日、評価時に提示した試料情報と参照画像、マップの条件名を知っていたかを残す。
- 条件名への先入観を減らすため、可能な場合は条件名を隠し、提示順をランダム化する。ランダム化した場合は対応表とseedを保存する。
- 劣化位置との対応、不自然な細片化、過度な平滑化、健全と判断する領域との分離、反復間で同じ構造が現れるかを、共通の観点として記録する。
- 段階評定や順位を使う場合も、それは人間の視覚判断の整合度であり、画素単位のground truthや劣化検出精度ではないと明記する。

評価者数、独立評価の有無、具体的な目視rubricと段階、条件名の隠し方、提示順、意見が一致しない場合の扱いはOpenとする。
条件名や結果を知った状態で行う探索的な目視はblind評価とは呼ばず、解釈に用いる成果物とともに確認範囲を明記する。
