# 全体学習後の可視化と解釈

## 1. ステータス

**Fixed / 任意の責務マップはOpen**

本文例の選択基準と試料IDは第4.2節で事前固定済み。実行時の記録事項は
実験プロトコル第11.2節を参照する。

2026-09-08、全体可視化にvMF mixtureを追加し、同じ表現に対するCosine-KMeansとの
分割の違いを試料表面の領域・境界から探索的に読む方針をユーザーが確定した。
これは実験開始後の追加決定であり、当初から事前固定していたとは記述しない。

CV結果からbest条件を選択せず、事前に定めた次の4条件を全試料を対象としてfitまたは学習する。
本書のraw SNVは、本番前処理済みの256次元SNVを表現変換せず直接使用するbaselineを指す。

| ID | 条件 | 役割 |
| --- | --- | --- |
| B0 | raw SNV | 入力空間baseline |
| B1 | PCA | 線形baseline |
| M00 | MAE 50% | 標準MAE |
| M11 | Aug-MAE 50% | 提案条件 |

すべての条件をCV開始前に指定した共通の代表表示値$K_0=8$で、Cosine-KMeansとvMF mixtureの
両方によりクラスタリングする。比較対象は4表現条件 × 2クラスタリング手法とする。
この段階は全試料を対象とする記述的解析であり、劣化との対応は探索的な仮説として扱う。
未知試料への適用時の空間的一貫性・指定摂動への安定性の根拠は5-fold CVに置く。
CVと全体学習のどちらも、劣化検出の正確さを定量的に検証するものではない。

全49試料のそれぞれから、実験プロトコルと同じ$q=8192$画素を一様ランダム・非復元抽出する。
全条件・両手法で同じ抽出座標を共有し、抽出画素を全試料でまとめた集合を使ってPCA・ChemoMAEの
fitまたは学習を行う。得られた各条件の同じ表現にCosine-KMeansとvMFをfitする。
fit後はモデルを固定して全試料の全有効画素へ推論し、マップとスペクトルの要約を作成する。
試料ごとのクラスタリング再fitは行わない。
全体学習用の抽出seedと座標manifestも保存する。fitに用いる試料は全試料だが、fit画素と表示画素は区別する。
B0は256次元SNVの単位表現、PCAとChemoMAEはCVと同じ16次元・L2正規化を用いる。
ChemoMAEの表現抽出は全可視・augmentationなし・FP32とする。
表示用の2次元投影はクラスタリング後の補助表示とし、元の表現に代えてクラスタリングへ入力しない。

全体可視化は、CVの反復ID 1に対応する事前固定seed設定を使い、必要な表現変換器のfitまたは学習と、
各条件・各手法のクラスタリングをそれぞれ1回行う。
CVで最も良かったseedを選ばない。M00とM11の全体学習は計2回で、CVの105学習とは別に実施する。
vMFは全体学習用のPCA・encoderと各条件の表現を再利用するため、追加する表現学習は0回、
vMF fitは4条件で計4回となる。
[CV補助実験の735 fits](experiment_protocol.md#vmf-supplementary)とは別枠で管理する。
複数反復に対する分割の再現性はCVのARIで報告し、この1回の可視化だけで再現性を主張しない。

vMFの利用版・モデル・退化成分の扱いは実験プロトコル第5.2節を継承する。
初期化は共通fit画素の表現に対するcosine kmeans++型とし、対応する全体可視化用の`kmeans_seed`を使う。
追加restartやKMeans最終中心からのwarm startは行わず、手法間で初期方向が一致するとは仮定しない。
同第5.2.3節で現在Openの数値仕様を確定・検証してから、CV補助実験と全体解釈で設定を共用する。
未決定の値を既定値で暗黙に埋めない。
全体解釈の成果物はCVの評価・OOF集計から分け、手法別のfit記録に元の表現・抽出座標・設定・
source hashとの対応、vMFの成分診断と完了・失敗の状態を残す。

## 2. ラベル規約

- 背景は0とする。
- クラスタは1から$K_0$までとする。
- vMFのhard labelは最大posterior責務の成分から割り当てる。
- クラスタ番号に順序または劣化度の意味を持たせない。
- ラベル整列前後でクラスタ所属そのものは変更しない。

## 3. Hungarian matching

### 3.1 基準条件

B0のraw SNVをCosine-KMeansで分割したpartitionを、全8組の共通基準とする。
Cosine-KMeansのB1・M00・M11と、vMFのB0・B1・M00・M11の計7組を、
それぞれ独立にこの基準へ直接matchingする。

試料ごとのmatching、および別の条件や手法を経由する連鎖matchingは行わない。

### 3.2 contingency matrix

全試料について全8組に共通して有効な木材画素だけを使用する。
共通基準のラベルを$i$、比較対象（表現条件$c$・クラスタリング手法$a$）のhard labelを$j$として、

$$
C_{ij}
=\sum_p\mathbf{1}[y_p^{(\mathrm{ref})}=i\land y_p^{(c,a)}=j]
$$

を作る。背景0はmatrixおよび割当から除外する。

Hungarian algorithmにより

$$
\max_{\pi}\sum_{i=1}^{K_0}C_{i,\pi(i)}
$$

となる1対1対応$\pi$を比較対象ごとに求め、比較対象のラベルを共通基準のラベル番号へ置換する。

### 3.3 適用範囲

得られた対応は全試料で共通とし、次へ一貫して適用する。

- label mapの色と番号
- cluster sizeおよびoccupancy
- 代表スペクトルと差スペクトル
- cluster別の補助統計

元の成分番号と表示番号の対応を保存し、vMFの成分別診断にも同じ対応を適用する。
matchingは表示と対応関係の確認を目的とし、異なる条件・手法のクラスタが同一の意味を持つことを保証しない。
contingency matrixまたはmatching後のoverlapを併記し、対応の弱いクラスタを可視化上の同一色だけで解釈しない。
このmatchingは全共通画素数に基づくため、大きい試料の寄与が大きい。表示ラベルの整列として用い、
試料macroの定量評価や共通基準を正解とした精度評価には転用しない。

条件・手法間の比較には、本番前処理HDF5の`pixel_row_col`で同一と確認できる画素だけを使用する。
条件・手法ごとに画素集合を変更したり、label mapを位置補正したりしない。

## 4. 可視化・解釈項目

本節の規約は、前処理診断を含むリポジトリ内のすべての可視化へ適用する。

- figure titleおよびaxes titleを付けない。
- 図の意味、試料ID、条件名およびpanelの説明はcaptionまたはファイル名で管理する。
- 軸ラベル、目盛、legendおよびcolorbar labelは、値の解釈に必要な場合は表示する。

| 項目 | 目的 |
| --- | --- |
| label map | 条件・手法間でクラスタの試料表面の空間分布を比較する |
| contingency/overlap matrix | 共通基準に対するクラスタ対応の強さを確認する |
| representative spectra | 各クラスタのNIRスペクトル形状を確認する |
| difference spectra | クラスタ差が大きい波長帯を確認する |
| cluster size distribution / occupancy | collapse、過小クラスタ、不均衡を確認する |
| latent PCA/UMAP | 潜在空間の構造を補助的に観察する |

raw SNV、PCA、M00、M11と両クラスタリング手法で、同じ試料順、同じlabel palette、同じ表示範囲を使用する。

### 4.1 スペクトルの表示と要約

- 各条件・各手法のhard labelによるクラスタ所属を用い、同じ本番前処理データの反射率とSNVを要約する。
  潜在表現やdecoderの再構成値を実測スペクトルと呼ばない。
- 試料・クラスタごとに、所属する全有効画素のband別中央値を求める。全体の代表線は、そのクラスタが
  存在する試料の中央値スペクトルをband別に中央値化し、試料間の四分位範囲を併記する。
- クラスタが存在しない試料は代表線の集約対象に含めず、0や他のスペクトルで埋めない。各クラスタの
  寄与試料数・試料ID・画素数を示し、代表線ごとに構成試料が異なることを明示する。
- 1試料だけが寄与するクラスタでは試料間のばらつきは評価できないと記す。band別要約は実在する
  1画素のスペクトルや成分濃度の推定値を意味しない。
- difference spectraは上記代表線の差として表示し、差を取る条件・クラスタと引き算の向きを記す。
  別々の構成試料から作った代表線の差を、同一試料のpairedな化学変化とは解釈しない。
- SNVでは画素ごとのoffsetとscaleを除いているため、SNV振幅差を吸収量や成分量の直接比較に使わない。

### 4.3 クラスタリング手法間の空間マップ比較

同じ全体学習済み表現に対する分割の違いを読むため、各試料の比較図は行をCosine-KMeans・vMF、
列をB0・B1・M00・M11とする2行4列で構成する。両手法で第4.2節の固定済み7代表試料を共用する。
panelの条件・手法・試料IDはcaptionまたはファイル名に記し、figure titleとaxes titleは付けない。

hard label mapと併せて、共通基準へのcontingency/overlap、試料別occupancyと使用クラスタ数、
第4.1節に従う代表・差スペクトルを両手法について保存する。領域の広がり、境界の位置、
分割・統合の違いを、クラスタ対応の強さと占有率を踏まえて記述する。
同一色の領域が増えたことや境界が減ったことだけを改善とせず、単一クラスタへの集中も確認する。

この図は全体学習用のPCA・encoder・クラスタリングモデルから作る。CVのfold別モデルの予測を
継ぎ合わせた図とは区別し、全体fitによるマップの違いをCVのscore差の直接的な再現とは扱わない。
CVでの比較は[評価指標第8.4節](evaluation_metrics.md#vmf-evaluation)に従って報告し、
本節ではクラスタリング手法によって表現の読み取りがどう変わるかを探索的に解釈する。

### 4.4 任意の責務マップ（Open）

vMFの画素ごとの最大posterior責務を、割当が拮抗する場所を観察するための追加表示候補とする。
必須のhard label mapとは分け、採用の有無と表示範囲・配色・背景の扱いはOpenとする。
採用する場合は、結果を見る前に表示規約を確定する。主評価や条件・K・seedの選択には使わない。

## 5. 解釈上の制約

潜在空間と試料表面の対応に関する探索的仮説と、silhouette・LLA・LFRを併読する際の注意は
[評価指標第8.5節](evaluation_metrics.md#interpretation-notes)を参照する。

- 正解劣化ラベルがないため、クラスタを直ちに劣化classと断定しない。
- label map、代表スペクトル、差スペクトルおよび試料情報を合わせて解釈する。
- vMFの責務はfitした混合モデル内での割当を表し、化学的な正解確率、劣化度または成分存在比とは解釈しない。
  hard labelの代表スペクトルも純粋成分を意味しない。責務の大きさだけで表現条件の優劣を決めない。
- 劣化との対応は探索的解釈に限定する。スペクトル形状の違いや既報の吸収帯との整合性は仮説を
  支える観察として記述し、独立した劣化測定に代わる定量的な検証とは扱わない。
- 吸収帯の変化だけから劣化機構や化学成分量を一意に決定しない。樹種、材組織、含水状態、測定面の
  状態などの代替説明を、確認できた情報と未確認の可能性に分けて記述する。
- 全体学習後の解釈を、未知試料に対する劣化検出性能の根拠にしない。CVの空間的一貫性・摂動安定性も
  劣化との対応を保証するものではない。
- UMAPなどの2次元投影だけで表現の優劣を決めない。
- 可視化結果を用いて主条件を入れ替えたり、best条件を事後定義したりしない。
