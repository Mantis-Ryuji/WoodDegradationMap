# ドキュメント案内

`docs/`は研究の問い・採用理由・仕様・実施記録を整理する場所、
[`thesis/`](../thesis/README.md)はそれらを読者に説明する論文原稿の場所である。
初めて読む場合は[研究の目的](research_overview.md)、実験を再開する場合は[ToDo](../ToDo.md)、
原稿を読む場合は[修士論文ドラフト](../thesis/README.md)から進む。

## 目的別の入口

| 目的 | 読む順序 | 分かること |
| --- | --- | --- |
| 研究の論旨をつかむ | [研究概要](research_overview.md) → [ChemoMAEの位置づけ](chemomae_positioning.md) → [関連研究](related_work.md) | 問いと証拠の対応、手法の採用理由、先行研究との共通点・相違点 |
| 条件と定義を確認する | [研究設計](design/README.md) → 対象の仕様書 → [決定記録](design/decisions.md) | 現行条件・Open事項と、それを決めた時点 |
| 実験を進める | [ToDo](../ToDo.md) → [runbook](experiment_runbook.md) → [検証履歴](verification_history.md) | 次の作業、CLI・再開・完了判定・保存先、実施済みの確認 |
| 途中結果を考える | [解釈メモ](interpretation_notes.md) → 対応する成果物・定義 | 観察した範囲、説明候補、まだ確かめていない点 |
| 論文として読む・書く | [原稿案内](../thesis/README.md) → [構成案](../thesis/outline.md)・[執筆計画](../thesis/writing_plan.md) | 現在の本文・付録、章ごとの問い、資料と執筆作業の対応 |

## 論点の置き場所と文書間の関係

| 論点・情報 | 主に記載する場所 | 他の文書へ説明するときの扱い |
| --- | --- | --- |
| 研究の問いと、どの証拠で答えるか | 研究概要 | 論文の緒言と全体構成の軸にする |
| なぜこの学習課題・構成を選ぶか | ChemoMAEの位置づけ | 本文には手法の理解に必要な理由を残し、数理的な導出は付録Bで展開する |
| 先行研究との対応と確認範囲 | 関連研究 | 既報の結果と本構成からの推論を分け、原稿の引用・書誌を整える |
| 研究条件・数式の定義・データ契約 | `docs/design/` | 仕様の正とする。原稿では必要な条件を文章・式・表で説明する |
| 決定の経緯と適用範囲 | 設計上の決定記録 | CV開始後の追加判断を、開始前の固定条件として遡及記載しない |
| 進捗・操作・実測値 | ToDo・runbook・検証履歴 | 順に、次の作業・実行方法・実施済みの事実を確認する |
| 観察とその説明候補 | 解釈メモ | 試料・fold・反復・Kを明記し、仮説と未実施の確認候補を区別する |
| 読者に提示する論証 | `thesis/chapters/`・`thesis/appendices/` | 本文に主要な定義・前提・限界を置き、付録に導出・再現の詳細を置く |

同じ論点でも、採用理由、厳密な導出、実測結果の読み方では説明の役割が異なる。
それぞれの文書で必要な説明を完結させ、詳しい根拠へリンクする。追記は関連する論点の節へ組み込み、
時系列で残す必要のある実行・決定の記録は履歴文書に置く。

Fixedは採用済みという意味であり、実装・実行済みを意味しない。Open事項は原稿でも未確定と明示する。
進捗やrunの数値を各文書へ重複転記せず、原稿確定時に実施記録と照合する。
既存成果物のconfig・manifest・実行記録は、説明の整理に合わせて書き換えない。

## 混同しやすい用語と範囲

| 用語 | 本リポジトリでの意味 |
| --- | --- |
| raw SNV / B0 | 前処理済み256次元SNVを直接使うbaseline。センサのraw強度ではない |
| 試料 | `KYOw...`で識別する分割・集計単位。同一原材との関係は確認できた範囲で扱う |
| 学習反復 / repeat | 同じsplit・画素集合に対する3反復。B0・B1ではKMeansの反復を含む |
| 評価摂動反復 / draw | LFR用に各摂動を5回生成する反復。学習反復とは別 |
| OOF | 各試料をtrainに含めないfoldモデルから得る予測・評価 |
| 全体fit | 全49試料からの共通抽出画素でfit・学習し、全試料を記述する解析 |
| matching | 分割を変えずに表示番号を対応づける操作。クラスタに劣化順序や共通の化学的意味を与えない |
| clean | 追加noise・shiftを加える前の観測。測定ノイズのない真値ではない |

可視化は用途に応じて[OOF sanity](design/oof_sanity_visualization.md)と
[全体fit後の可視化](design/visualization_and_interpretation.md)へ進む。
