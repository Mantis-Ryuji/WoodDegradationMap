# ドキュメント案内

初めて読む場合は[研究の目的](research_overview.md)、作業を再開する場合は[ToDo](../ToDo.md)から進む。
固定条件、実行手順、実施済みの確認、探索的な所見は、次の文書で管理する。

## 目的別の入口

| 知りたいこと | 文書 |
| --- | --- |
| 何を問う研究か、どう説明するか | [研究の目的と説明文](research_overview.md) |
| なぜMAE・denoising・単位潜在を使うか | [ChemoMAEの位置づけ](chemomae_positioning.md) |
| どの先行研究と何が違うか | [関連研究・参考文献](related_work.md) |

| CLI、再開、完了判定、保存先 | [実験runbook](experiment_runbook.md) |
| どこまで実行・検証したか | [検証履歴](verification_history.md) |
| 途中の可視化をどう読んだか | [実験途中の所見と解釈メモ](interpretation_notes.md) |
| いつ、何を決定・変更したか | [設計上の決定記録](design/decisions.md) |

## 文書の役割

- **設計**は研究条件・数式・データ契約の正とする。実装済みかどうかはToDoとrunbookで確認する。
- **進捗**はToDoに集約する。完了runの実測値と確認結果は検証履歴に置く。
- **解釈メモ**は観察した試料・fold・反復・Kを明記し、仮説を確定事項へ昇格させない。
- **決定記録**はCV開始後の追加判断を含む。現行仕様を過去に遡って事前固定済みとは書かない。
- **文献**は出典と当時の確認範囲を保つ。既報の結果、本構成からの推論、本研究の未検証事項を区別する。

新しい記録は対応する文書へ追記し、同じ数値・仕様・進捗を複数箇所へ複製しない。
概要では要点と定義先へのリンクを示す。既存の成果物に含まれるconfig・manifest・実行記録は、文書整理に伴って書き換えない。

## 混同しやすい用語と範囲

| 用語 | 本リポジトリでの意味 |
| --- | --- |
| raw SNV / B0 | 前処理済み256次元SNVを直接使うbaseline。センサのraw強度ではない |
| 試料 | `KYOw...`で識別する分割・集計単位。同一原材との関係は確認できた範囲で扱う |
| 学習反復 / repeat | 同じsplit・画素集合に対する3反復。B0・B1ではKMeansの反復を含む |
| 評価摂動反復 / draw | LFR用に各摂動を5回生成する反復。学習反復とは別 |
| OOF | 各試料をtrainに含めないfoldモデルから得る予測・評価 |
| 全体fit | 全49試料からの共通抽出画素でfit・学習し、全試料を記述する解析 |
| matching | 分割を変えずに表示番号を対応づける操作。クラスタに劣化順序や共通の化学的意味を与えない |
| clean | 追加noise・shiftを加える前の観測。測定ノイズのない真値ではない |

可視化は用途に応じて[OOF sanity](design/oof_sanity_visualization.md)と
[全体fit後の可視化](design/visualization_and_interpretation.md)へ進む。
